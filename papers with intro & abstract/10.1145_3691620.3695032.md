# Beyond Manual Modeling: Automating GUI Model Generation Using Design Documents

- **Year:** 2024
- **Venue/Source:** ASE
- **DOI:** 10.1145/3691620.3695032

## Metadata

- **se_area:** model-based testing
- **se_task:** automated GUI model generation from design documents
- **cv_technique:** pre-trained CV models for GUI element recognition
- **platform:** mobile
- **rationale:** CV identifies GUI elements and their intended behaviors from design documents to construct formal IFML models without reverse engineering code
- **artifact_type:** UI/UX design document
- **eval_method:** evaluated with an industry partner on commercial apps; comparative analysis of manual, automated, and hybrid modeling for MBT
- **challenges:** reverse-engineered models are consistent with code and thus unsuitable for detecting functional issues in MBT

## Summary

DemGen extracts GUI models from design documents instead of runtime code, using CV to bridge the gap between design intent and the formal model. This makes the generated models useful for finding functional bugs that code-derived models would miss.
