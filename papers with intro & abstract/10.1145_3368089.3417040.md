# Towards learning visual semantics

- **Year:** 2020
- **Venue/Source:** ESEC/FSE
- **DOI:** 10.1145/3368089.3417040

## Metadata

- **se_area:** Design
- **se_task:** Automated high-level functional description generation from software visual outputs
- **cv_technique:** Image/video understanding (visual element labeling + NL generation)
- **platform:** General
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** Early results demonstrating VSL feasibility
- **challenges:** Only applicable to software with meaningful visual outputs; requires NL generation quality

## Summary

A vision paper proposing Visual Semantics Learning: deriving functional descriptions from what software looks like instead of reading its code. An ambitious premise with limited evaluation, though publication at ESEC/FSE gives it credibility. Useful to cite in the survey's discussion of future directions for CV in SE.
