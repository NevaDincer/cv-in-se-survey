# Translating Video Recordings of Complex Mobile App UI Gestures into Replayable Scenarios

- **Year:** 2023
- **Venue/Source:** TSE
- **DOI:** 10.1109/TSE.2022.3192279

## Metadata

- **se_area:** Testing
- **se_task:** Video-to-replayable-scenario translation for Android GUI testing
- **cv_technique:** Object detection + image classification (gesture detection from video frames)
- **platform:** Mobile
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** 90.2% action reproduction on native apps; 83% on hybrid apps; 243 videos from 90+ apps
- **challenges:** Multi-finger gesture detection; hybrid app support; no GUI metadata available

## Summary

The first purely CV-based record-and-replay tool for Android, needing no GUI metadata. Detects and classifies gestures from video frames, then replays them on device. Extends to hybrid apps. An industrial case study with three partners, published in TSE with strong evaluation.
