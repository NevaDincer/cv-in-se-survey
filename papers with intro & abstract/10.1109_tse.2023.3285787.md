# Mobile App Crowdsourced Test Report Consistency Detection via Deep Image-and-Text Fusion Understanding

- **Year:** 2021
- **Venue/Source:** TSE
- **DOI:** 10.1109/tse.2023.3285787

## Metadata

- **se_area:** crowdsourced testing
- **se_task:** crowdsourced test report consistency detection
- **cv_technique:** deep learning for GUI screenshot feature extraction in image-text fusion
- **platform:** Android
- **rationale:** CV extracts screenshot features to detect whether bug descriptions are consistent with their attached screenshots
- **artifact_type:** mobile app screenshot
- **eval_method:** evaluated on 22k+ test reports; user study confirming practical value for report review efficiency
- **challenges:** only 18.07% of crowdsourced reports are consistent; inconsistency wastes developer review effort

## Summary

ReCoDe first classifies reports by bug type from text, then applies type-specific strategies combining screenshot CV features to judge text-image consistency. Complements SemCluster and DeepPrior in the crowdsourced testing cluster, but targets report quality instead of deduplication or prioritization.
