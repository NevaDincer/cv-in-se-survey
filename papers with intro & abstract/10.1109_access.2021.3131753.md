# GUI Widget Detection and Intent Generation via Image Understanding

- **Year:** 2021
- **Venue/Source:** IEEE Access

- **eval_method:** Accuracy metrics
- **challenges:** Scalability to large and diverse application corpora; Limited ground truth data

## Summary

Targets aerospace control software testing. Detects GUI widgets via image matching, then uses a CNN encoder-decoder to generate natural language intent descriptions for each widget. Achieves an IoU of 0.81 for detection and a BLEU-1 of 0.567 for intent generation. The domain (aerospace) is niche, but the pipeline is generalizable, useful as an example of combining widget localization with natural-language intent labeling for test automation.
