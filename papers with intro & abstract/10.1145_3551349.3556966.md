# Accelerating OCR-Based Widget Localization for Test Automation of GUI

- **Year:** 2023
- **Venue/Source:** ASE
- **DOI:** 10.1145/3551349.3556966

## Metadata

- **se_area:** GUI test automation
- **se_task:** widget localization via OCR acceleration
- **cv_technique:** OCR with Label Text Screening preprocessing
- **platform:** desktop
- **rationale:** CV pipeline accelerates label text localization on GUI screens to make OCR-based test automation practical without GPU
- **artifact_type:** GUI screenshot
- **eval_method:** below 0.5s for ~60% of 4K cases on CPU; 4x+ faster than Tesseract, PaddleOCR, and EasyOCR baselines
- **challenges:** OCR too slow for real-world test automation use on GPU-free machines at 4K resolution

## Summary

LTS avoids running full OCR on entire screens by pre-filtering regions unlikely to contain short label text, breaking open the OCR black box. It is a practical engineering contribution for GUI test tooling, not a novel ML approach. Useful reference for the discussion of CV performance bottlenecks in SE tools.
