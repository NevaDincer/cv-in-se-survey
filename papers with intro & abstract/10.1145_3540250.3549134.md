# Avgust: automating usage-based test generation from videos of app executions

- **Year:** 2022
- **Venue/Source:** ESEC/FSE
- **DOI:** 10.1145/3540250.3549134

## Metadata

- **se_area:** mobile app testing
- **se_task:** usage-based test generation from screen recordings
- **cv_technique:** neural image understanding for UI screen and action classification
- **platform:** Android
- **rationale:** CV processes video frames to classify UI screens and user inputs, encoding app usage semantics into a state machine for test synthesis
- **artifact_type:** mobile app screen recording
- **eval_method:** 69% test success rate on 374 videos across 18 apps; classifiers outperform state of the art
- **challenges:** generating usage-based tests requires understanding UI screen semantics and user input intent, not just maximizing coverage

## Summary

Avgust generalizes V2S by targeting usage-based tests instead of simple replay. It encodes video-derived usage patterns into an app-agnostic state machine, then migrates them to new target apps. Part of the CV-for-video-to-test-generation cluster, following V2S.
