# Appaction: Automatic GUI Interaction for Mobile Apps via Holistic Widget Perception

- **Year:** 2023
- **Venue/Source:** ESEC/FSE
- **DOI:** 10.1145/3611643.3613885

## Metadata

- **se_area:** mobile app testing
- **se_task:** automatic GUI interaction and valid input generation
- **cv_technique:** multimodal model for GUI widget understanding
- **platform:** Android
- **rationale:** CV analyzes GUI screenshots holistically to understand widget semantics and generate contextually valid test inputs
- **artifact_type:** mobile app screenshot
- **eval_method:** deployed at Meituan with 600M+ users; demonstrated effectiveness on numerous commercial form pages
- **challenges:** diverse and complex commercial GUIs (e.g., order forms) require understanding widget context beyond simple element detection

## Summary

Appaction learns from human GUI perception experience to infer valid inputs for form-heavy commercial apps, going beyond click-based exploration to semantic input generation.

Another industrial-scale deployment paper alongside [[10.1109_HNICEM60674.2023.10589222]]; useful for contrasting CV adoption patterns across different companies and app types.
