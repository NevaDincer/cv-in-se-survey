# Semantic Test Repair for Web Applications

- **Year:** 2023
- **Venue/Source:** ESEC/FSE
- **DOI:** 10.1145/3611643.3616324

## Metadata

- **se_area:** web app testing
- **se_task:** automated web test script repair
- **cv_technique:** visual appearance matching
- **platform:** web
- **rationale:** visual element appearances are used alongside semantic similarity to locate broken web elements during test repair
- **artifact_type:** webpage screenshot
- **eval_method:** 84% average repair ratio on 6 real-world web apps, outperforms 3 baselines
- **challenges:** DOM-based and visual locators both fail when semantic context of elements is ignored

## Summary

Semter captures semantic information from test executions to repair broken locators, complementing visual approaches instead of replacing them. CV is one signal among several; semantics is the main contribution.
