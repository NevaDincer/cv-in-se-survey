# GIFdroid: Automated Replay of Visual Bug Reports for Android Apps

- **Year:** 2022
- **Venue/Source:** ICSE
- **DOI:** 10.1145/3510003.3510048

## Metadata

- **se_area:** Maintenance
- **se_task:** Automated bug report replay from screen recordings
- **cv_technique:** Image processing (keyframe extraction; GUI state matching via image similarity)
- **platform:** Mobile
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** Automated experiments + user study on accuracy and efficiency
- **challenges:** Screen recordings are long and contain unclear actions; non-technical users cannot write precise bug descriptions

## Summary

Extracts keyframes from a bug report GIF or video, maps them to GUI Transition Graph states, and generates a replay trace. A lightweight CV approach. Connects to [[10.1109_TSE.2022.3192279]], which also translates video into replayable scenarios but for general testing, not bug reproduction specifically. ICSE 2022.
