# Object detection for graphical user interface: Old fashioned or deep learning or a combination?

- **Year:** 2020
- **Venue/Source:** ESEC/FSE
- **DOI:** 10.1145/3368089.3409691

## Metadata

- **se_area:** Testing
- **se_task:** GUI element detection from screenshots
- **cv_technique:** Hybrid: traditional image processing (canny edge; contours) + deep learning (text detection)
- **platform:** General
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** Empirical study on 50k+ GUI images; final evaluation on 25k images; outperforms 7 baselines
- **challenges:** CV methods not designed for GUI-specific characteristics; localization accuracy demands higher than natural images

## Summary

First large-scale empirical comparison of GUI element detection methods, with 7 baselines across 50,000 images. Main finding: neither pure traditional methods nor pure deep learning wins outright; a hybrid coarse-to-fine approach performs best. A foundational paper for GUI understanding research, with 129 citations.
