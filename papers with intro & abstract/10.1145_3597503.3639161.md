# Practical Non-Intrusive GUI Exploration Testing with Visual-based Robotic Arms

- **Year:** 2024
- **Venue/Source:** ICSE 2024
- **DOI:** 10.1145/3597503.3639161

## Metadata

- **se_area:** Testing
- **se_task:** Non-intrusive GUI exploration testing via robotic arm and CV
- **cv_technique:** CV-based screen and widget detection (adaptive to different screen sizes)
- **platform:** Mobile
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** Tested on 20 real-world mobile apps; industrial embedded system case study
- **challenges:** Fixed screen assumption in prior work; XY-plane only robotic arms; compatibility bugs ignored

## Summary

A physical 4-DOF robotic arm clicks the screen, so no framework injection is needed. CV detects widgets from screenshots. Targets embedded or custom OS environments where intrusive testing is impossible. A more sophisticated version of the [[10.1109_UBMK63289.2024.10773486]] paper, from ICSE.
