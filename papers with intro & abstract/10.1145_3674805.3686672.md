# Data Analysis Tools Affect Outcomes of Eye-Tracking Studies

- **Year:** 2024
- **Venue/Source:** EMSE
- **DOI:** 10.1145/3674805.3686672

## Metadata

- **se_area:** empirical SE / developer studies
- **se_task:** eye-tracking data analysis standardization
- **cv_technique:** 
- **platform:** 
- **rationale:** no CV involvement; eye-tracking hardware captures gaze data but no computer vision processing is applied
- **artifact_type:** 
- **eval_method:** systematic mapping study plus reproduction on 3 public eye-tracking datasets using Tobii, iTrace, and Ogama
- **challenges:** lack of standardization across analysis tools leads to non-reproducible study conclusions

## Scope note

Edge case for inclusion. Eye tracking involves visual data collection, but this paper is about statistical analysis tool comparability, not CV.

## Summary

Shows that tool choice (Tobii, iTrace, Ogama) significantly changes eye-tracking study results in SE research. CV is not used.
