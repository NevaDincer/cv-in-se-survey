# AutoTestUI-Automated Test Case Generation from UI Screenshots

- **Year:** 2025
- **Venue/Source:** ICECA 2025
- **DOI:** 10.1109/ICECA66444.2025.11383091

## Metadata

- **se_area:** Testing
- **se_task:** Automated test case generation from UI screenshots without source code access
- **cv_technique:** CV (UI element detection); OCR; NLP (semantic classification)
- **platform:** General
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** 70% reduction in testing time; 88% UI element detection accuracy
- **challenges:** Traditional frameworks require source code access; manual scripting not scalable

## Summary

CV extracts UI elements, OCR reads text, NLP classifies components, then maps to executable QA/UAT test scripts.

Similar motivation to [[10.1016_j.jss.2022.111431]] and [[10.1007_978-981-15-7234-0_4]] but adds NLP semantic layer.

Low venue, limited novelty over existing work.
