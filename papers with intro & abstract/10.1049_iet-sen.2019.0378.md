# Deep learning-based prototyping of android GUI from hand-drawn mockups

- **Year:** 2020
- **Venue/Source:** IET Software
- **DOI:** 10.1049/iet-sen.2019.0378

## Metadata

- **se_area:** code generation
- **se_task:** hand-drawn sketch-to-Android GUI prototype generation
- **cv_technique:** YOLOv5 object detection for GUI element detection and classification
- **platform:** Android
- **rationale:** CV detects and classifies hand-drawn GUI elements via YOLOv5 then aligns them to generate Android prototypes
- **artifact_type:** hand-drawn mockup
- **eval_method:** 98.54% recognition accuracy on hand-drawn GUI structures from 5 developers
- **challenges:** hand-drawn input is underexplored compared to computer-generated mockups; irregular strokes make detection harder

## Summary

Uses YOLOv5 to detect and classify hand-drawn GUI components, then assembles them into Android prototypes matching the sketch layout. One of the few sketch-to-code papers that uses hand-drawn input instead of wireframes. Useful early reference for the sketch-based GUI generation subcluster.
