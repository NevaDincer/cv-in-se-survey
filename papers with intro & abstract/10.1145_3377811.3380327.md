# Unblind Your Apps: Predicting Natural-Language Labels for Mobile GUI Components by Deep Learning

- **Year:** 2020
- **Venue/Source:** ICSE
- **DOI:** 10.1145/3377811.3380327

## Metadata

- **se_area:** accessibility
- **se_task:** automatic accessibility label generation for image-based GUI components
- **cv_technique:** deep learning image classifier for button label prediction
- **platform:** Android
- **rationale:** CV classifies image-based button icons to predict natural-language accessibility labels for screen reader support
- **artifact_type:** mobile app screenshot
- **eval_method:** outperforms real Android developers in label quality; trained on large-scale Google Play apps; analysis of 10,408 apps showing 77%+ have missing labels
- **challenges:** over 77% of Android apps have missing accessibility labels due to developer unawareness and lack of visual context for description

## Summary

LabelDroid learns from commercial app icons to generate screen reader labels for unlabeled image buttons, directly improving app accessibility at scale. A foundational paper for the CV-enabling-accessibility cluster. It predates MotorEase and complements it by addressing label generation instead of violation detection.
