# Unlocking the conversion of Web Screenshots into HTML Code with the WebSight Dataset

- **Year:** 2024
- **Venue/Source:** arXiv
- **DOI:** 10.48550/arxiv.2403.09029

## Metadata

- **se_area:** code generation
- **se_task:** screenshot-to-HTML code generation
- **cv_technique:** vision-language model fine-tuned on screenshot-HTML pairs
- **platform:** web
- **rationale:** VLM processes webpage screenshots to generate corresponding functional HTML code
- **artifact_type:** webpage screenshot
- **eval_method:** fine-tuned VLM demonstrates proficiency on 2M synthetic screenshot-HTML pairs from WebSight dataset
- **challenges:** lack of high-quality paired screenshot-HTML datasets limited prior progress on this task

## Summary

Introduces WebSight, a 2M-pair synthetic screenshot-HTML dataset, and shows that a fine-tuned VLM can convert webpage screenshots into working HTML. The dataset is the main contribution. Complements DCGen and LayoutCoder in the screenshot-to-code cluster with a data-centric contribution instead of an architectural one.
