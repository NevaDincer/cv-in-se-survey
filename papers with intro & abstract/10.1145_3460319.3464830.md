# GUIDER: GUI structure and vision co-guided test script repair for Android apps

- **Year:** 2021
- **Venue/Source:** ISSTA
- **DOI:** 10.1145/3460319.3464830

## Metadata

- **se_area:** mobile app testing
- **se_task:** GUI test script repair after app evolution
- **cv_technique:** visual widget appearance matching
- **platform:** Android
- **rationale:** CV provides visual widget features that are combined with structural DOM information to identify widget correspondences across app versions
- **artifact_type:** mobile app screenshot
- **eval_method:** 88.8% and 54.9% more test actions repaired correctly over visual-only and structure-only baselines on WeChat
- **challenges:** neither visual nor structural information alone is sufficient to reliably match widgets after app updates

## Summary

GUIDER fuses visual and structural widget features for test repair, showing that the combination outperforms either signal alone by a large margin. Clean ablation story.

Good reference for the "multimodal widget matching" cluster alongside UITestFix and Semter.
