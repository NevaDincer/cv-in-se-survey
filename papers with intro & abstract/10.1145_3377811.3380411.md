# Seenomaly: Vision-based linting of GUI animation effects against design-don't guidelines

- **Year:** 2020
- **Venue/Source:** ICSE
- **DOI:** 10.1145/3377811.3380411

## Metadata

- **se_area:** GUI Testing
- **se_task:** Linting GUI animations against design guidelines
- **cv_technique:** Unsupervised adversarial autoencoder for screencast classification
- **platform:** Mobile
- **rationale:** CV model watches unlabeled animation recordings and groups them to detect design-don't violations without manual labeling
- **artifact_type:** GUI animation screencast
- **eval_method:** Experiments on synthetic and real-world GUI animation datasets; effectiveness and practicality assessed
- **challenges:** Insufficient labeled GUI animations; static analysis and image comparison tools cannot perceive motion

## Summary

Frames animation linting as unsupervised multi-class screencast classification, sidestepping the labeled-data problem with an adversarial autoencoder. The model learns to reconstruct normal animations, flagging ones that deviate as guideline violations. Published at ICSE 2020, and unusual for its focus on temporal visual artifacts instead of static screenshots.
