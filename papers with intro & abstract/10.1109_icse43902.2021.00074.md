# GUIGAN: Learning to Generate GUI Designs Using Generative Adversarial Networks

- **Year:** 2021
- **Venue/Source:** ICSE
- **DOI:** 10.1109/icse43902.2021.00074

## Metadata

- **se_area:** Design
- **se_task:** Automated GUI design generation from existing app screenshots
- **cv_technique:** GAN (SeqGAN-based component selection and composition)
- **platform:** Mobile
- **rationale:** Context-driven
- **artifact_type:** Component
- **eval_method:** 30.77% improvement in FID; 12.35% in 1-NNA over baselines; user study
- **challenges:** Gap between textual query and visual intent; IP concerns with direct reuse; outdated design styles

## Summary

Formulates GUI generation as sequence generation, similar to NLP, instead of pixel generation. Reuses real component subtrees from existing apps to compose novel designs. Bridges Gallery D.C. search and sketch-to-code generation. ICSE 2021, with strong quantitative results and a user study.
