# Mobile Bug Report Reproduction via Global Search on the App UI Model

- **Year:** 2024
- **Venue/Source:** PACM SE
- **DOI:** 10.1145/3660824

## Metadata

- **se_area:** bug reporting
- **se_task:** automated bug report reproduction for mobile apps
- **cv_technique:** GUI screenshot-based UI model construction
- **platform:** Android
- **rationale:** CV captures UI states as screenshots to build the app UI model used for global Markov-based step matching
- **artifact_type:** mobile app screenshot
- **eval_method:** 94% reproduction rate on 72 real-world bug reports; 93% on reports with missing steps; outperforms ReCDroid, Yakusu, ReproBot
- **challenges:** missing or inaccurate bug report steps cause greedy search approaches to fail at incorrect UI states

## Summary

Roam reframes bug reproduction as a Markov model search problem, using dynamic programming to find globally optimal step-to-event matches instead of greedy local matching. CV's role is building the UI state graph. Relevant for the bug reproduction cluster alongside ScopeDroid and CAPdroid.
