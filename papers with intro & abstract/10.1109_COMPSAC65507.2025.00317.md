# Exploring the Black-Box: Testing Image Synthesis Systems through Metamorphic Exploration

- **Year:** 2025
- **Venue/Source:** COMPSAC
- **DOI:** 10.1109/COMPSAC65507.2025.00317

## Metadata

- **se_area:** DL system testing
- **se_task:** metamorphic testing of image synthesis networks
- **cv_technique:** visible-infrared image fusion network
- **platform:** 
- **rationale:** CV model (image synthesis network) is the system under test; metamorphic relations are defined over image inputs/outputs to detect defects without a test oracle
- **artifact_type:** synthesized image
- **eval_method:** identified tensor dimension manipulation error in a visible-infrared fusion network
- **challenges:** defining valid metamorphic relations for image synthesis without destroying contextual semantics

## Scope note

Edge case for inclusion. Relevant to the survey's testing-AI/CV-systems angle, not the CV-as-tool angle.

## Summary

Applies metamorphic exploration to test deep learning image synthesis systems where traditional oracles fail. Uses a visible-infrared fusion network as a case study and shows that hypothesized metamorphic relations can expose subtle implementation bugs, such as tensor dimension errors.
