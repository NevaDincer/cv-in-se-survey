# GuiEvo: Automated Evolution of Mobile Application GUIs

- **Year:** 2024
- **Venue/Source:** MSR
- **DOI:** 10.1145/3643991.3644936

## Metadata

- **se_area:** Maintenance
- **se_task:** Automated GUI evolution by detecting changes between releases and mock-ups
- **cv_technique:** CV-based GUI change detection (mock-up vs. existing release)
- **platform:** Mobile
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** Accuracy >85%; precision; recall; F1; tree edit distance (avg 5.9)
- **challenges:** Manual GUI evolution is time-consuming; mock-up-to-code gap

## Summary

Detects diff between existing GUI and new mock-up, then auto-generates updated UI metadata.

Bridges design and maintenance
