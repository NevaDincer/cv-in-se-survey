# PredART: Towards Automatic Oracle Prediction of Object Placements in Augmented Reality

- **Year:** 2023
- **Venue/Source:** ASE
- **DOI:** 10.1145/3551349.3561160

## Metadata

- **se_area:** AR app testing
- **se_task:** virtual object placement quality prediction as test oracle
- **cv_technique:** hybrid neural network for image regression
- **platform:** AR mobile apps
- **rationale:** CV predicts human perception scores for virtual object placements to serve as an automated test oracle
- **artifact_type:** AR app screenshot
- **eval_method:** 85.0% accuracy, MAE 0.047, RMSE 0.091 on 480 screenshots
- **challenges:** placement correctness is subjective and perceptual, requiring crowd-sourced ground truth and regression rather than classification

## Summary

PredART is the direct predecessor of VOPA. It addresses the same AR placement oracle problem, but frames it as regression over human rating scores instead of binary classification. Reading both together shows the evolution from score prediction to error detection in AR testing.
