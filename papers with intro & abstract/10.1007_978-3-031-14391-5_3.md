# GUI Element Detection from Mobile UI Images Using YOLOv5

- **Year:** 2022
- **Venue/Source:** MobiWIS
- **DOI:** 10.1007/978-3-031-14391-5_3

## Metadata

- **se_area:** GUI design
- **se_task:** GUI element detection from mobile UI screenshots
- **cv_technique:** YOLOv5 object detection
- **platform:** mobile, web
- **rationale:** CV detects GUI elements from UI images to enable downstream automation and cross-platform design tasks
- **artifact_type:** mobile app screenshot
- **eval_method:** +15.69% mAP over SSD baseline on VINS dataset (450 UI samples for testing)
- **challenges:** GUI element detection must handle diverse element types across platforms while remaining fast enough for practical automation

## Summary

Benchmarks YOLOv5 for GUI element detection using the VINS dataset, outperforming the prior SSD-based approach. The technical contribution is incremental, swapping in a newer detector. Useful as a methods reference for the GUI element detection infrastructure that underlies many other papers in the survey.
