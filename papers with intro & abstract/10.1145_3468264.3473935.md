# An empirical study of GUI widget detection for industrial mobile games

- **Year:** 2021
- **Venue/Source:** ESEC/FSE
- **DOI:** 10.1145/3468264.3473935

## Metadata

- **se_area:** Testing
- **se_task:** GUI widget detection for mobile game testing automation
- **cv_technique:** CV-based GUI widget detection (comparative study of existing methods)
- **platform:** Game
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** Survey at NetEase Games; comparative study showing general methods fail on games; first game GUI benchmark
- **challenges:** High diversity and density of game GUI widgets; existing methods not designed for game UIs

## Summary

Main finding: general-purpose GUI widget detection fails on games because of high widget density and diversity. This is the first benchmark for mobile game GUI widget detection, done in an industrial collaboration with NetEase Games. Pairs directly with [[10.1145_3611643.3613867]] in the game testing cluster. ESEC/FSE 2021.
