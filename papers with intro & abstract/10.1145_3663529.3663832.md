# Neat: Mobile App Layout Similarity Comparison Based on Graph Convolutional Networks

- **Year:** 2024
- **Venue/Source:** Companion ACM International Conference on the Foundations of Software Engineering
- **DOI:** 10.1145/3663529.3663832

## Metadata

- **se_area:** mobile app testing
- **se_task:** GUI layout similarity verification across devices and versions
- **cv_technique:** GUI element detection, GCN-based layout feature extraction
- **platform:** mobile
- **rationale:** CV detects UI elements and extracts layout features to automate cross-device layout assertion without source code access
- **artifact_type:** mobile app screenshot
- **eval_method:** empirical evaluation plus industrial application deployment reported
- **challenges:** multi-model cross-version layout verification is too resource-intensive for manual testing

## Summary

Neat treats layout comparison as a graph similarity problem, where UI elements become nodes and spatial relations become edges, then a GCN encodes the structure for comparison. It is non-intrusive and end-to-end, which makes it deployable in CI pipelines. A close relative of [[10.1109_ICSTW55395.2022.00052]], but with a graph-structural approach instead of a pixel-level one.
