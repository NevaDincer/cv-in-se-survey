# Semantic matching in GUI test reuse

- **Year:** 2024
- **Venue/Source:** EMSE
- **DOI:** 10.1007/s10664-023-10406-8

## Metadata

- **se_area:** mobile app testing
- **se_task:** GUI test case migration via semantic matching
- **cv_technique:** 
- **platform:** Android
- **rationale:** no CV involvement; approach relies entirely on text embedding and semantic similarity for widget matching
- **artifact_type:** 
- **eval_method:** 8,099 GUI events across 337 test configurations; sentence-level embeddings outperform word-level
- **challenges:** effective test reuse depends heavily on the choice of semantic matching algorithm and event type filtering

## Scope note

No CV is used. Edge case for inclusion; important context for the test migration cluster, but the approach is purely text-based.

## Summary

A journal extension of the ISSTA 2021 SemFinder empirical study, offering a more comprehensive framework and evaluation.
