# Towards LLM-Based Automatic Playtest

- **Year:** 2025
- **Venue/Source:** ACM International Conference on the Foundations of Software Engineering
- **DOI:** 10.1145/3696630.3728700

## Metadata

- **se_area:** game testing
- **se_task:** automated playtesting of match-3 games
- **cv_technique:** screenshot-to-matrix conversion for game state extraction
- **platform:** desktop
- **rationale:** CV parses game board screenshots into numeric matrices to make visual game states consumable by an LLM for action planning
- **artifact_type:** game screenshot
- **eval_method:** higher code coverage and more crashes than 3 baseline tools on CasseBonbons open-source game
- **challenges:** non-text games lack APIs for state description, making direct LLM application impractical without visual parsing

## Scope note

Edge case for inclusion. CV is a thin preprocessing layer here, not a substantive technique.

## Summary

Lap converts match-3 game screenshots into numeric matrices as a lightweight CV preprocessing step, then feeds them to ChatGPT-o1-mini for move generation. CV's role is minimal, just image-to-matrix conversion, with the core contribution being LLM-driven game logic reasoning.
