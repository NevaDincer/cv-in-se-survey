# Effective, Platform-Independent GUI Testing via Image Embedding and Reinforcement Learning

- **Year:** 2024
- **Venue/Source:** TOSEM
- **DOI:** 10.1145/3674728

## Metadata

- **se_area:** Testing
- **se_task:** Platform-independent automated GUI exploration testing
- **cv_technique:** CNN (widget extraction + type classification); RNN (layout embedding)
- **platform:** General
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** 6.3-41.4% more code coverage on mobile; 1.5-51.1% on web; 128 unique bugs detected
- **challenges:** Hybrid/custom widgets invisible to layout parsers; reward function design for RL

## Summary

Main insight: mobile and web widgets are visually identical across platforms, so CV can extract them without layout file access. Combines microscopic (widget) and macroscopic (layout tree) state embedding for RL reward design. The first platform-independent RL-based GUI testing tool.
