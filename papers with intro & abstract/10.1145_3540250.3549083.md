# Cross-device record and replay for Android apps

- **Year:** 2022
- **Venue/Source:** ESEC/FSE
- **DOI:** 10.1145/3540250.3549083

## Metadata

- **se_area:** mobile app testing
- **se_task:** cross-device test script record and replay
- **cv_technique:** GUI visual structure analysis for widget matching
- **platform:** Android
- **rationale:** visual GUI structure is used to adapt recorded interactions to different screen sizes and orientations during replay
- **artifact_type:** mobile app screenshot
- **eval_method:** over 1,000 replay settings; competitive with state-of-the-art on same-device replay and beyond known non-search-based tools on cross-device cases
- **challenges:** apps restructure their GUIs responsively across screen sizes, breaking naive locator-based replay

## Summary

Rx uses a greedy one-pass algorithm guided by the least-surprise principle in GUI design to resolve widget identity across devices. CV supports widget matching here; it is not the central contribution. Relevant alongside LIRAT for the cross-device test portability cluster, but simpler and Android-only.
