# Automatically recognizing the semantic elements from UML class diagram images

- **Year:** 2022
- **Venue/Source:** JSS
- **DOI:** 10.1016/j.jss.2022.111431

## Metadata

- **se_area:** Maintenance
- **se_task:** Semantic element extraction from UML class diagram images
- **cv_technique:** Rectangle clustering; polygonal line merging; image processing (no deep learning)
- **platform:** General
- **rationale:** Context-driven
- **artifact_type:** Document
- **eval_method:** 30 images from 3 UML tools; 50 open-source diagrams; promising precision/recall
- **challenges:** Tool-specific style variations; low resolution impact on relationship detection

## Summary

Same problem as [[10.1109_MODELS-C59198.2023.00099]] but different approach: traditional image processing instead of deep learning.

Survey finding that 73.72% of design models are stored as images --strong motivation cite.
