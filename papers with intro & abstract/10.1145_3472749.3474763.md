# Screen Parsing: Towards Reverse Engineering of UI Models from Screenshots

- **Year:** 2021
- **Venue/Source:** UIST
- **DOI:** 10.1145/3472749.3474763

## Metadata

- **se_area:** GUI design
- **se_task:** UI element detection and hierarchical grouping from screenshots
- **cv_technique:** deep learning for joint UI element detection and semantic relationship prediction
- **platform:** mobile
- **rationale:** CV predicts UI elements and their structural groupings from raw pixels to enable downstream SE tasks without developer-provided metadata
- **artifact_type:** mobile app screenshot
- **eval_method:** outperforms current systems by up to 23% in UI model accuracy
- **challenges:** inferring semantic groupings between elements from pixels requires both detection and relational reasoning

## Summary

Defines screen parsing as a combined detection and grouping task, enabling UI similarity search, accessibility enhancement, and code generation from a single model. A foundational infrastructure paper; its downstream applications map directly to multiple clusters in the survey. A precursor to EGFE and the Gestalt grouping work.
