# Design-Implementation Discrepancy Analysis for Mobile Application Interfaces Using Object Recognition

- **Year:** 2024
- **Venue/Source:** ICIET 2024
- **DOI:** 10.1109/ICIET60671.2024.10542829

## Metadata

- **se_area:** Maintenance
- **se_task:** Automated design-to-implementation discrepancy detection in mobile GUIs
- **cv_technique:** Image processing (component detection); Hungarian algorithm (component matching)
- **platform:** Mobile
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** Component type and location comparison between design and implementation images
- **challenges:** Manual verification is time-consuming; layout deviations due to technical constraints

## Summary

Compares Figma/prototype images against implemented app screenshots using CV. Similar to [[10.1145_3643991.3644936]], but this one focuses on discrepancy detection, not automated evolution.
