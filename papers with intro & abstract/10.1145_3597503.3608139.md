# On Using GUI Interaction Data to Improve Text Retrieval-Based Bug Localization

- **Year:** 2023
- **Venue/Source:** ICSE
- **DOI:** 10.1145/3597503.3608139

## Metadata

- **se_area:** Maintenance
- **se_task:** GUI-augmented text retrieval for bug localization
- **cv_technique:** GUI screenshot interaction data (for file filtering; boosting; query reformulation)
- **platform:** Mobile
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** Hits@10 improvement of 13-18% on 80 bug reports from 39 Android apps
- **challenges:** Semantic gap between bug report text and source code identifiers

## Summary

Uses GUI interaction screenshots from bug reproduction to augment text retrieval for bug localization. Not pure CV bridges visual and textual information. Practical gain: 13-18% improvement in top-10 file retrieval. Connects GIFdroid (989) reproduction line to bug localization research. ICSE 2023.
