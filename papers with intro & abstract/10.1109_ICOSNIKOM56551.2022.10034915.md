# Making DelProctor Proctoring Applications Using OpenCV

- **Year:** 2022
- **Venue/Source:** ICOSNIKOM 2022
- **DOI:** 10.1109/ICOSNIKOM56551.2022.10034915

## Metadata

- **se_area:** Software Application Development
- **se_task:** Online exam proctoring via face verification and fraud detection
- **cv_technique:** Face detection and matching via OpenCV
- **platform:** Desktop
- **rationale:** CV used to verify examinee identity and flag cheating behavior during online exams
- **artifact_type:** Webcam feed
- **eval_method:** Qualitative comparison against human supervisors and existing tools like Moodle Proctoring
- **challenges:** Processing load distributed to client to reduce server burden; no quantitative accuracy metrics reported

## Scope note

Edge case for inclusion. CV is used as an off-the-shelf tool with no novel CV methodology.

## Summary

Builds a Moodle-integrated proctoring app where OpenCV handles face matching on the client side instead of the server. CV is essentially a deployment vehicle here, not a research contribution. The paper's value is in the system architecture and its integration with the LMS.
