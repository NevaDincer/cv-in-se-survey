# Data-driven accessibility repair revisited: on the effectiveness of generating labels for icons in Android apps

- **Year:** 2021
- **Venue/Source:** ESEC/FSE
- **DOI:** 10.1145/3468264.3468604

## Metadata

- **se_area:** accessibility
- **se_task:** context-aware icon label generation for accessibility
- **cv_technique:** deep learning with multi-source context for icon image classification
- **platform:** Android
- **rationale:** CV classifies icon images enriched with contextual usage information to generate accurate accessibility labels
- **artifact_type:** mobile app icon
- **eval_method:** outperforms LabelDroid in both user study and automatic evaluation; shows icon images alone are insufficient
- **challenges:** icon images lack sufficient information for accurate label prediction without surrounding usage context

## Summary

COALA extends and critiques LabelDroid directly, showing that icon image alone is insufficient and that usage context significantly improves label quality. The finding that automatically extracted labeled data requires caution is an important methodological note for the survey. An important paper for the CV-plus-context accessibility labeling discussion.
