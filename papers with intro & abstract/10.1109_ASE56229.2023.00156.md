# ATOM: Automated Black-Box Testing of Multi-Label Image Classification Systems

- **Year:** 2023
- **Venue/Source:** ASE
- **DOI:** 10.1109/ASE56229.2023.00156

## Metadata

- **se_area:** DL system testing
- **se_task:** black-box testing of multi-label image classification systems
- **cv_technique:** metamorphic testing with image processing operations as metamorphic relations
- **platform:** 
- **rationale:** CV classification systems are the systems under test; metamorphic relations are applied to images to detect label combination errors
- **artifact_type:** real-world image
- **eval_method:** 6,049 errors across VOC and COCO datasets with 5 DNN models each; 92% of 587 industrial errors confirmed by developers
- **challenges:** exponential label combination space makes exhaustive testing infeasible; realistic test images needed for industrial acceptance

## Scope note

The CV system here is the thing under test, not the testing tool. This is an edge case for inclusion because the paper tests a CV system instead of using CV for an SE task.

## Summary

Uses image search and NLP to collect realistic test images for k-label combinations, then applies metamorphic testing to detect classification errors.
