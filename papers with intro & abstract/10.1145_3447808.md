# How Should I Improve the UI of My App?

- **Year:** 2021
- **Venue/Source:** TOSEM
- **DOI:** 10.1145/3447808

## Metadata

- **se_area:** requirements and design
- **se_task:** UI issue analysis from user reviews
- **cv_technique:** 
- **platform:** Android
- **rationale:** no CV involvement; study analyzes text reviews to identify UI issue types and owner-user interaction patterns
- **artifact_type:** 
- **eval_method:** 3M+ UI-related reviews from 22,199 free and 9,380 non-free apps; 17 UI issue types identified from 1,447 manually coded reviews
- **challenges:** identifying actionable UI improvement signals from noisy and subjective user review text at scale

## Scope note

Edge case for inclusion. The subject is UI quality, but the method is NLP-based review mining, not visual analysis.

## Summary

Large-scale empirical study identifying 17 UI issue types from Google Play reviews and 8 owner-response patterns. No CV is used.
