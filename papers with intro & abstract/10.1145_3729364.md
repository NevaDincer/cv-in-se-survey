# Divide-and-Conquer: Generating UI Code from Screenshots

- **Year:** 2025
- **Venue/Source:** PACM SE
- **DOI:** 10.1145/3729364

## Metadata

- **se_area:** code generation
- **se_task:** screenshot-to-UI code generation
- **cv_technique:** screenshot segmentation for MLLM-based code generation
- **platform:** web
- **rationale:** CV segments screenshots into smaller visual units to reduce element omission and distortion in MLLM-generated UI code
- **artifact_type:** webpage screenshot
- **eval_method:** up to 15% visual similarity and 8% code similarity improvement over baseline MLLMs on real-world websites
- **challenges:** MLLMs generate omitted, distorted, or misarranged elements when processing full-page screenshots as a single input

## Summary

DCGen decomposes a screenshot into manageable segments, generates code per segment, then reassembles them, solving the visual granularity problem for UI code generation. Complements LayoutCoder and DeclarUI in the screenshot-to-code cluster, using a simpler segment-based decomposition strategy instead of explicit layout trees.
