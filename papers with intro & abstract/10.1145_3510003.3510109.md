# If a Human Can See It, So Should Your System: Reliability Requirements for Machine Vision Components

- **Year:** 2022
- **Venue/Source:** ICSE
- **DOI:** 10.1145/3510003.3510109

## Metadata

- **se_area:** Requirements Engineering
- **se_task:** Defining and verifying reliability requirements for ML-based vision components
- **cv_technique:** Image classification models under image transformations
- **platform:** General
- **rationale:** Proposes SE-style reliability requirements for CV components using human performance as a correctness baseline
- **artifact_type:** Transformed images (brightness, blur, rotation etc.)
- **eval_method:** 13 pre-trained image classification models; ~2000 human participants across 8 transformation types
- **challenges:** ML-based MVCs lack formally specified requirements; existing testing methods miss reliability gaps detected by this approach

## Summary

Frames CV component quality as a requirements engineering problem, not just a benchmark problem. Human performance data from 2,000 participants is used to set the reliability bar, making the requirements both principled and machine-verifiable. A strong fit for surveys covering testing or quality assurance of ML/CV components in software systems.
