- **Year:** 2020
- **Venue/Source:** CCC 2020
- **DOI:** 10.23919/CCC50068.2020.9189199

## Metadata

- **se_area:** Testing
- **se_task:** Automated UI testing for camera hardware products via video image processing
- **cv_technique:** Video image processing (UI state verification from captured video output)
- **platform:** Desktop
- **rationale:** Context-driven
- **artifact_type:** Full-interface

## Summary

CV reads camera video output to verify UI state during automated testing. Hardware-in-the-loop like RoScript and the POS paper, but for camera products.

Low venue (Chinese Control Conference), limited novelty.

Niche embedded hardware testing use case.
