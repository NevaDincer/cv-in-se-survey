# Gallery D.C.: Auto-created GUI Component Gallery for Design Search

- **Year:** 2022
- **Venue/Source:** ICSE-Companion 2022
- **DOI:** 10.1145/3510454.3516873

## Metadata

- **se_area:** Design
- **se_task:** GUI component search and design inspiration discovery
- **cv_technique:** Faster R-CNN (GUI component detection from app screenshots)
- **platform:** Mobile
- **rationale:** Context-driven
- **artifact_type:** Component
- **eval_method:** Informal evaluation with 7 professional designers; 68k+ GUI designs indexed
- **challenges:** App introduction screenshots lack hierarchy metadata; artwork vs real-app design gap

## Summary

Indexes 11 types of GUI components from millions of real Android apps via CV-based reverse engineering. Targets design inspiration, not testing. Uses app store introduction screenshots as an untapped design resource -- interesting dataset angle.
