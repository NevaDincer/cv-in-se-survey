# Integrating Traversal and Visual-based Techniques to Initiate UI Exploration Scripting

- **Year:** 2020
- **Venue/Source:** 3rd International Conference on Computers in Management and Business
- **DOI:** 10.1145/3383845.3383890

## Metadata

- **se_area:** GUI test automation
- **se_task:** automated UI test script generation via traversal and visual element detection
- **cv_technique:** OpenCV-based GUI element detection as fallback when Accessibility API is unavailable
- **platform:** desktop
- **rationale:** CV detects GUI elements from screenshots when platform accessibility APIs are inaccessible, enabling test script generation across diverse platforms
- **artifact_type:** application screenshot
- **eval_method:** demonstrated on two open-source applications
- **challenges:** accessibility APIs are unavailable on some OS and application combinations, requiring a visual fallback

## Summary

Lightweight framework that combines API-based traversal with OpenCV as a fallback for GUI element detection when accessibility support is absent. Thin on evaluation.

Useful as an early example of CV as a platform-agnostic fallback strategy in test automation tooling.
