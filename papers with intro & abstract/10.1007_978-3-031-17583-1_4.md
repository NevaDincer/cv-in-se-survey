# SpiderTailed: A Tool for Detecting Presentation Failures Using Screenshots and DOM Extraction

- **Year:** 2023
- **Venue/Source:** Learning and Analytics in Intelligent Systems
- **DOI:** 10.1007/978-3-031-17583-1_4

## Metadata

- **se_area:** Testing
- **se_task:** Presentation failure detection in web GUI regression testing
- **cv_technique:** Image processing (visual property extraction per DOM element)
- **platform:** Web
- **rationale:** Context-driven
- **artifact_type:** Component
- **eval_method:** Comparison with manual observation test
- **challenges:** Direct image comparison causes misdetections due to large pixel differences

## Summary

Extracts abstract visual properties per DOM element instead of raw pixel diff, which is smarter than naive screenshot comparison. Targets regression testing in agile contexts. Similar in motivation to the Tricentis paper, but simpler and element-level.
