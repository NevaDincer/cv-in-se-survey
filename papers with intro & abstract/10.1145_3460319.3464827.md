# Semantic matching of GUI events for test reuse: are we there yet?

- **Year:** 2021
- **Venue/Source:** ISSTA
- **DOI:** 10.1145/3460319.3464827

## Metadata

- **se_area:** mobile app testing
- **se_task:** semantic GUI event matching for test reuse
- **cv_technique:** 
- **platform:** Android
- **rationale:** no CV involvement; approach relies purely on semantic text similarity between widget labels and event descriptions
- **artifact_type:** 
- **eval_method:** 253 matching configurations, 337 queries, 8,099 GUI events; SemFinder outperforms existing solutions
- **challenges:** textual widget information alone is often insufficient for reliable cross-app event matching

## Scope note

Edge case for inclusion. No CV is used, but it is frequently cited alongside vision-based widget matching papers in the test migration cluster.

## Summary

A comprehensive empirical study benchmarking semantic GUI event matching configurations for test reuse, proposing SemFinder as the best performer.
