# Image-based Bug Oracle Automation for Bug Report Reproduction Using Widget Detection

- **Year:** 2021
- **Venue/Source:** ICSE
- **DOI:** 10.1109/SEAI52285.2021.9477528

## Metadata

- **se_area:** Bug Reproduction
- **se_task:** Automated bug oracle verification via screenshot comparison
- **cv_technique:** Object detection for GUI widget extraction; structural tree comparison
- **platform:** Mobile (Android)
- **rationale:** CV parses oracle and runtime screenshots into widget hierarchies to check semantic equivalence without pixel-level sensitivity
- **artifact_type:** Bug report error screenshot
- **eval_method:** 80.8% accuracy on 52 real-world Android bug reports; compared against pixel-level tools
- **challenges:** Pixel-level comparison fails across devices, edited images, and dynamic content (usernames, dates)

## Summary

Reframes bug oracle verification as structural image comparison instead of pixel diff, which holds up well against device scaling and user-specific data. Widget detection builds a dummy hierarchy tree from both screenshots and checks tree similarity within a deviation threshold. A solid empirical setup on real Android apps with a clear baseline comparison.
