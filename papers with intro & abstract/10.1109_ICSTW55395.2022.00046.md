# Win GUI Crawler: A tool prototype for desktop GUI image and metadata collection

- **Year:** 2022
- **Venue/Source:** ICSTW 2022
- **DOI:** 10.1109/ICSTW55395.2022.00046

## Metadata

- **se_area:** Testing
- **se_task:** Automated desktop GUI dataset collection for ML-based element detection
- **cv_technique:** Bounding box extraction and filtering from Windows UI automation
- **platform:** Desktop
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** Evaluated on several popular Windows applications; prototype demonstration
- **challenges:** No publicly available desktop GUI image database; existing datasets only cover mobile and web

## Summary

Dataset collection tool, not a CV application per se. Fills the gap left by Rico (mobile) and web datasets for desktop domain.

Enables future ML-based GUI element detection on Windows. Motivation paper for the desktop GUI testing research gap.
