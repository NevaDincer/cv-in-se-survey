# RoScript: A visual script driven truly non-intrusive robotic testing system for touch screen applications

- **Year:** 2020
- **Venue/Source:** ICSE
- **DOI:** 10.1145/3377811.3380431

## Metadata

- **se_area:** Testing
- **se_task:** Non-intrusive robotic test automation for touch screen applications
- **cv_technique:** CV-based action recording from video; visual script matching for test execution
- **platform:** General
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** 21 apps on 6 devices; 104 test scenarios; 90% action execution accuracy; 85% recording accuracy
- **challenges:** Closed/uncommon systems not supported by Appium or Sikuli; test script creation cost

## Summary

Physical robot drives touch screen testing without any framework injection. Records human interactions from video into replayable test scripts via CV. Earlier and simpler version of the [[10.1109_UBMK63289.2024.10773486]] line of work. ICSE 2020, strong multi-device evaluation.
