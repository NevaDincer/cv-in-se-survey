# Synthesis-Based Enhancement for GUI Test Case Migration

- **Year:** 2024
- **Venue/Source:** ISSTA
- **DOI:** 10.1145/3650212.3680327

## Metadata

- **se_area:** mobile app testing
- **se_task:** GUI test case migration and synthesis
- **cv_technique:** GUI state matching via screenshots
- **platform:** Android
- **rationale:** GUI states are identified and sequenced using visual screen representations to align and merge migrated test cases
- **artifact_type:** mobile app screenshot
- **eval_method:** 86%, 333%, 300% improvement over Craftdroid, AppFlow, ATM on 30 apps, 34 functionalities, 127 test cases
- **challenges:** individually migrated test cases are incomplete and require synthesis to become directly executable

## Summary

Synthesizes a single functional test case by merging multiple imperfect migrations from different source apps, using GUI state sequences to align events and assertions. CV supports state identification here; it is not the central contribution. Relevant for the cross-app test reuse cluster.
