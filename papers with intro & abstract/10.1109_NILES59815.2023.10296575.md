# Owl Eye: An AI-Driven Visual Testing Tool

- **Year:** 2023
- **Venue/Source:** NILES 2023
- **DOI:** 10.1109/NILES59815.2023.10296575

## Metadata

- **se_area:** Testing
- **se_task:** Visual defect detection in GUI across platforms
- **cv_technique:** Object detection (traditional image processing + deep learning); tree-based object matching
- **platform:** General
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** Change classification (translation; scaling; color change; removal)
- **challenges:** Data quality and availability; resistance to adoption over conventional tools

## Summary

Detects visual bugs pixel comparison misses, detects translation, scaling, color, removal via object-level tree matching.

Platform and source code independent.

Similar to [[10.1007_s13748-025-00408-6]] (tricentis) but simpler and lower venue.
