# DeepLSH: Deep Locality-Sensitive Hash Learning for Fast and Efficient Near-Duplicate Crash Report Detection

- **Year:** 2024
- **Venue/Source:** ICSE
- **DOI:** 10.1145/3597503.3639146

## Metadata

- **se_area:** bug reporting
- **se_task:** crash report deduplication and bucketing
- **cv_technique:** Siamese DNN with locality-sensitive hashing
- **platform:** 
- **rationale:** no CV involvement; Siamese DNN operates on crash report text/stack traces, not visual data
- **artifact_type:** 
- **eval_method:** experiments on a newly released crash report dataset comparing LSH approximation quality across similarity metrics
- **challenges:** deriving locality-sensitive hash functions for advanced crash bucketing metrics like Jaccard and Cosine

## Scope note

Edge case for inclusion. The DNN architecture originates in CV but is applied here to a purely textual SE task.

## Summary

DeepLSH adapts Siamese networks and LSH from the CV/retrieval literature to crash report bucketing, but the input is textual crash data, not images.
