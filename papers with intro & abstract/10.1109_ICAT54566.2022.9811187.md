# Application of Machine Learning for GUI Test Automation

- **Year:** 2022
- **Venue/Source:** ICAT 2022
- **DOI:** 10.1109/ICAT54566.2022.9811187

## Metadata

- **se_area:** GUI Testing
- **se_task:** ML-assisted test case selection and automation for EDA tool GUI
- **cv_technique:** Image classification via VGG16
- **platform:** Desktop
- **rationale:** VGG16 classifies GUI states to reduce manual effort in test case selection within a regression testing suite
- **artifact_type:** GUI screenshot
- **eval_method:** Accuracy and precision metrics on EDA tool test data
- **challenges:** EDA tools have unique GUI complexity; no single test framework covers the full toolchain

## Scope note

Edge case for inclusion because CV plays a supporting role rather than being the central contribution.

## Summary

Case study applying VGG16 image classification to a niche domain, IC physical design EDA tools, as part of a three-module ML test framework. CV is one component among several here, not the core research contribution. Weak venue and narrow domain limit generalizability.
