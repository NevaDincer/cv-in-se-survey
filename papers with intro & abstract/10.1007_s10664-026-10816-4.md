# VLM-Fuzz: Vision Language Model Assisted Recursive Depth-First Search Exploration for Effective GUI Testing of Android Apps

- **Year:** 2026
- **Venue/Source:** EMSE
- **DOI:** 10.1007/s10664-026-10816-4

## Metadata

- **se_area:** Testing
- **se_task:** Automated Android GUI fuzzing for code coverage and crash detection
- **cv_technique:** VLM (on-demand GUI reasoning)
- **platform:** Mobile
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** Code coverage (class/method/line); crash detection (52 crashes in 12 apps)
- **challenges:** Complex dynamic GUI layouts; coordination between test states

## Summary

VLM is not used for every screen, only triggered on-demand for visually complex cases.

Hybrid with heuristic DFS. Outperforms APE and DeepGUI.

Good example of selective CV integration in Testing.
