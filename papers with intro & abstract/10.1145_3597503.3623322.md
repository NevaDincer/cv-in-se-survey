# Learning-based Widget Matching for Migrating GUI Test Cases

- **Year:** 2024
- **Venue/Source:** ICSE
- **DOI:** 10.1145/3597503.3623322

## Metadata

- **se_area:** mobile app testing
- **se_task:** GUI test case migration via widget matching
- **cv_technique:** visual widget feature extraction combined with BERT-based contextual matching
- **platform:** Android
- **rationale:** widget visual features are combined with contextual text embeddings to learn a matching model for cross-app widget identification
- **artifact_type:** mobile app screenshot
- **eval_method:** 76% Top1 event matching accuracy (+17% over baselines); 89% F1 on test case migration on 34 apps
- **challenges:** static word embeddings miss contextual semantics; class imbalance between positive and negative widget pairs degrades matching

## Summary

TEMdroid uses BERT with a two-stage hard-negative mining strategy to learn widget matching for test migration.

Complements the empirical study in [[10.1109_ASE56229.2023.00068]] by proposing a learned solution to the visual-only limitations identified there. Good pair for the "cross-app widget matching" cluster.
