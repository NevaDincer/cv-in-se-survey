# Learning to Denoise Raw Mobile UI Layouts for Improving Datasets at Scale

- **Year:** 2022
- **Venue/Source:** CHI
- **DOI:** 10.1145/3491102.3502042

## Metadata

- **se_area:** dataset and tooling
- **se_task:** mobile UI layout dataset denoising and annotation
- **cv_technique:** deep learning on screenshot-layout pairs for node validity and type classification
- **platform:** Android
- **rationale:** CV cross-references screenshots against raw UI layouts to remove invalid nodes and assign semantic types at scale
- **artifact_type:** mobile app screenshot
- **eval_method:** F1 82.7% for invalid node detection, 85.9% for type recognition on 59,555 annotated screens from Rico
- **challenges:** raw UI layout datasets contain noisy nodes that lack visual representation and generic types that hinder semantic analysis

## Summary

CLAY improves UI layout dataset quality by using screenshots as ground truth to clean and retype raw accessibility tree nodes. It is an infrastructure paper, not a testing or development tool itself, but it is foundational for downstream CV-based SE research that depends on clean UI layout data. Useful to cite when discussing dataset quality in the survey.
