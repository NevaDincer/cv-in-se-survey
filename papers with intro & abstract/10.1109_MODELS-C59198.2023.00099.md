# NEURAL-UML: Intelligent Recognition System of Structural Elements in UML Class Diagram

- **Year:** 2023
- **Venue/Source:** MODELS 2023
- **DOI:** 10.1109/MODELS-C59198.2023.00099

## Metadata

- **se_area:** Maintenance
- **se_task:** Automated semantic element recognition in UML class diagram images
- **cv_technique:** CNN (object detection + classification); deep learning
- **platform:** General
- **rationale:** Context-driven
- **artifact_type:** Document
- **eval_method:** Accuracy 92.59% and 94.11% on two subsets; IoU; F1 score
- **challenges:** High variability in diagram styles and tools; lack of annotated training data

## Summary

UML diagrams stored as images lose their semantic structure, CV recovers it.

Targets classes and six relationship types. New annotated dataset of 14500 diagrams released.

Useful cite for CV applied to design artifact recovery.
