# A Novel approach of GUI Mapping with image based widget detection and classification

- **Year:** 2021
- **Venue/Source:** ICIEM 2021
- **DOI:** 10.1109/ICIEM51511.2021.9445281

## Metadata

- **se_area:** Testing
- **se_task:** Automated web GUI widget detection and classification (labels, buttons, input boxes, checkboxes, links) directly from a target URL, to support automated test case generation for rapidly updated web applications
- **cv_technique:** OpenCV-based object detection using bounding boxes and color variation (unsupervised, no trained image repository); k-nearest neighbor (kNN) classifier for widget-type classification
- **platform:** Web
- **rationale:** ease of use (avoids building and maintaining a large labeled GUI-widget training set by taking a live URL as input instead); robustness (aimed at coping with continuously and rapidly updated GUI components, such as e-commerce sites)
- **artifact_type:** full-interface (web page screenshots with widgets highlighted via bounding boxes)
- **eval_method:** demonstrated on about 10 real-time websites (Gmail, Google, a government services portal, Instagram, LinkedIn, Twitter, Skype, Snapdeal, a generic sign-in page, Yahoo, Amazon), reporting per-site object-detection time (about 9.6 to 10.3 seconds per page) and a sample 32-screenshot detection report for Google.com; no accuracy, precision, or recall figures are actually computed, despite the abstract's claim of better accuracy
- **challenges:** the authors state that detection accuracy, classification accuracy, and testing-coverage probability will be calculated and presented in future work, meaning no quantitative accuracy evaluation exists in this paper; the technical description of the object-detection and kNN steps is shallow, with no architecture, training data, or parameter details given

## Scope note

The paper claims better accuracy in its abstract but never reports an actual accuracy, precision, or recall figure for detection or classification. The only quantitative results are per-site detection time and a raw coordinate report for Google.com. Worth treating with caution as an evaluation example.

## Summary

Proposes a lightweight, training-repository-free approach to automated web GUI testing. Instead of pretraining a widget classifier on a large labeled image dataset, the method takes a live URL as input, uses Selenium to drive a browser and trigger interactions, and applies OpenCV to detect widget bounding boxes and color variation directly on the resulting screenshots. Detected widgets are then classified into types (text field, button, combo box, list, tree, scroll bar, menu, menu item, toggle button, tabs, slider) via a kNN classifier, using simple visual heuristics: a screenshot that changes entirely gets inferred as a hyperlink or button trigger, a cursor-icon appearance gets inferred as an input box, and an in-page list gets inferred as a combo box. Demonstrated qualitatively across about ten well-known websites, with per-site object-detection timing consistently around 9.6 to 10.3 seconds per page. The motivation is cutting the cost of manually re-authoring test cases every time a fast-iterating web application updates its GUI.
