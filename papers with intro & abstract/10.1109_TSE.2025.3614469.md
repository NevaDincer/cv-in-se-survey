# Seeing is Believing: Vision-Driven Non-Crash Functional Bug Detection for Mobile Apps

- **Year:** 2025
- **Venue/Source:** TSE
- **DOI:** 10.1109/TSE.2025.3614469

## Metadata

- **se_area:** Testing
- **se_task:** Non-crash functional bug detection via visual GUI logic analysis
- **cv_technique:** MLLM (multi-agent; screenshot annotation + visual-textual alignment)
- **platform:** Mobile
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** 590 non-crash bugs; 14-112% recall boost over 12 baselines; 43 unknown bugs found on Google Play
- **challenges:** No reliable oracle for non-crash bugs; MLLM hallucination; token limit in exploration history

## Summary

61.3% of GitHub bug reports are non-crash bugs, a largely underexplored area. VisionDroid uses three MLLM agents (Explorer, Monitor, Detector) to understand GUI page transition logic, not just visual state. Functionality-aware chain-of-thought reduces hallucination. Published in TSE, with strong results.
