# STIFA: Crowdsourced Mobile Testing Report Selection Based on Text and Image Fusion Analysis

- **Year:** 2020
- **Venue/Source:** ASE
- **DOI:** 10.1145/3324884.3415300

## Metadata

- **se_area:** Testing
- **se_task:** Duplicate bug report detection in crowdsourced mobile testing
- **cv_technique:** Image feature extraction (screenshot analysis for bug context)
- **platform:** Mobile
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** 95.23% text feature extraction; 84.15% image feature extraction; 87.64% duplicate detection accuracy on 150 reports
- **challenges:** Existing tools treat screenshots and text independently; duplicate report noise reduces efficiency

## Summary

Fuses screenshot and text features to build a unified bug context for duplicate detection. Connects to [[10.1016_j.neucom.2024.127502]] in the crowdsourced testing theme, but focuses on report deduplication instead of test reproduction. Published at ASE, with solid accuracy results.
