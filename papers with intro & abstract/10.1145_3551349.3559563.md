# A model for automatic generating reusable code from multiple GUIs

- **Year:** 2023
- **Venue/Source:** ASE
- **DOI:** 10.1145/3551349.3559563

## Metadata

- **se_area:** code generation
- **se_task:** reusable UI component detection and code generation from GUI images
- **cv_technique:** visual element detection and recognition from GUI images
- **platform:** web, Android, iOS
- **rationale:** CV detects and recognizes visual elements from GUI images as the first step toward cross-platform code generation
- **artifact_type:** GUI screenshot
- **eval_method:** not reported; work-in-progress DSR study
- **challenges:** identifying reusable components across GUIs and representing them in a platform-agnostic way for code generators

## Summary

Early-stage design science research paper outlining a research agenda for GUI-to-code generation, with a focus on cross-GUI component reuse. The contribution is mostly problem framing, not a working system, and results are thin. Useful mainly as a reference point for GUI-to-code research.
