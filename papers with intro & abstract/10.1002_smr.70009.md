# cvrip: A Visual GUI Ripping Framework

- **Year:** 2025
- **Venue/Source:** JSEP
- **DOI:** 10.1002/smr.70009

## Metadata

- **se_area:** Testing
- **se_task:** Visual GUI ripping for cross-platform GUI model extraction
- **cv_technique:** YOLOv5 (widget detection); SSIM (state recognition)
- **platform:** Mobile
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** Exploration coverage vs. traditional ripping tools; action step comparison
- **challenges:** False widget detection; slower than traditional ripping due to CV overhead

## Summary

Traditional GUI ripping needs framework access

cvrip works from screenshots only, enabling cross-platform use.

Competitive coverage vs. state-of-the-art but slower.
