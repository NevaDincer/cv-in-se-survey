# Development of a Software Prototype for Assisting People with Quadriplegia: An Approach Based on Interface Analysis

- **Year:** 2025
- **Venue/Source:** Communications in Computer and Information Science
- **DOI:** 10.1007/978-3-031-75147-9_2

## Metadata

- **se_area:** Requirements
- **se_task:** Adaptive UI design for quadriplegia users via facial movement analysis
- **cv_technique:** OpenCV; MediaPipe (facial landmark detection; optical flow)
- **platform:** Desktop
- **rationale:** Context-driven
- **artifact_type:** Full-interface
- **eval_method:** Iterative user testing with quadriplegia users; movement map generation
- **challenges:** High customization needed per user; real-time processing constraints

## Summary

CV analyzes head, eye, and lip movements to generate personalized movement maps for adaptive UI design. Requirements elicitation via CV is an unusual angle here. The accessibility and SE intersection is similar to [[10.1145_3597503.3639167]], but this work is input-focused, not output testing.
