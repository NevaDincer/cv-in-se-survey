## Summary

MigratePro addresses a problem the authors identify in a preliminary study: existing GUI test case migration approaches (Craftdroid, AppFlow, ATM) frequently produce migrated test cases that are incomplete or non-functional, with 57–96% of generated cases failing to successfully test their target functionality across two benchmark datasets. Rather than proposing a new widget-matching technique, MigratePro is a post-hoc synthesis layer that combines multiple already-migrated test cases (from various source apps, for the same target functionality) into a single higher-quality test case. It works in two stages: first, test case generation, which collects GUI states reachable from the migrated test cases (via direct execution and greedy-random exploration), builds a functionality-specific state graph, and organizes events/assertions from all migrated test cases into a base test case following a topologically sorted state sequence; second, test case adjustment, which classifies events/assertions as should-be-included or should-be-removed based on execution success and frequency across the migrated test cases, then dynamically explores the target app to find "connection events" that make should-be-included but non-executable steps executable. Applied on top of Craftdroid, AppFlow, and ATM across 30 apps and 127 test cases, MigratePro improves availability (successfully-testing test cases) by 86%, 333%, and 300% respectively, and outperforms two more recent migration approaches (TRASM, Adaptdroid) by 45% availability and 31% coverage. Despite its clear software-engineering contribution to test migration, the paper contains no computer-vision component; all reasoning operates over structural GUI state/widget data rather than pixels or screenshots.
