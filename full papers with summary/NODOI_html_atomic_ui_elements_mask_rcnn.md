# HTML Atomic UI Elements Extraction from Hand-Drawn Website Images using Mask-RCNN and novel Multi-Pass Inference Technique

- **Year:** 2020
- **Venue/Source:** CLEF 2020 Working Notes, CEUR Workshop Proceedings, Vol-2696 (ImageCLEF 2020 DrawnUI task)
- **DOI:** Not assigned (CEUR-WS working notes paper, no DOI)

## Metadata

- **se_area:** development (automated construction of website UI structure from hand-drawn wireframe sketches, as a precursor step to code generation)
- **se_task:** object detection and localization of atomic UI elements, such as buttons, checkboxes, dropdowns, and text inputs, within photographed hand-drawn website and mobile app wireframes, as a first step toward automatically converting a sketch into a website layout
- **cv_technique:** Mask R-CNN (Feature Pyramid Network with a ResNet-101 backbone) for instance detection of UI elements, pretrained on COCO and fine-tuned via transfer learning on the competition dataset; an extensive OpenCV preprocessing pipeline including near-duplicate image removal by per-class label-count distance, DLIB-based shape extraction to compensate for underrepresented classes, grayscale conversion, image sharpening, Otsu's binarization, adaptive Gaussian thresholding, and connected-component noise removal; a novel Multi-Pass Inference technique that masks already-detected regions with the background color and reruns the model on the edited image to force detection of missed elements, merging the passes by confidence score and bounding-box IoU overlap
- **platform:** other (photographed hand-drawn paper or whiteboard sketches of website and mobile app wireframes, from the ImageCLEF 2020 DrawnUI dataset)
- **rationale:** automation (removing the need to manually translate a hand-drawn UI wireframe into code, letting people without tool or programming knowledge create interfaces directly from sketches); ease of use
- **artifact_type:** full-interface (whole photographed wireframe sketches containing multiple UI elements localized by bounding box)
- **eval_method:** ImageCLEF 2020 DrawnUI shared task dataset of 2,363 annotated hand-drawn images across 21 UI element classes, reduced to 1,306 after duplicate removal, evaluated against a held-out 587-image test set using Mean Average Precision at IoU greater than 0.5 (mAP), overall precision (OP), and overall recall (OR) as defined by the shared task; Run 1 (baseline Mask R-CNN, 200 epochs) scored mAP 57.34, OP 94.04, OR 41.7; Run 2 (Multi-Pass Inference added, 100 epochs with a stepped learning-rate schedule) scored mAP 63.73, OP 91.81, OR 50.1; Run 3 (Run 2 refined to keep only the highest-confidence second-pass boxes) scored mAP 64.12, OP 91.71, OR 49.6, placing third on the shared task leaderboard
- **challenges:** the dataset was heavily class-imbalanced, with labels like paragraph, button, header, image, and container vastly outnumbering rare classes such as textarea, stepperinput, and rating, a gap the DLIB-based shape-extraction step only partially addressed; images captured at steep angles distorted straight lines into diagonals and rectangles into parallelograms, complicating detection; the "image" class, defined as a rectangle with both diagonals drawn, frequently overlapped with other elements drawn on top of or beneath it, creating ambiguous bounding-box cases; the baseline Mask R-CNN model achieved high precision but low recall, systematically missing smaller UI elements, which motivated the multi-pass approach; the authors note that time and compute constraints prevented testing other baseline architectures such as EfficientDet, and suggest further work on attention mechanisms and additional inference passes

## Summary

This paper describes a system built for the ImageCLEF 2020 DrawnUI shared task, which asks participants to detect and localize atomic UI elements, such as buttons, checkboxes, and dropdowns, within photographs of hand-drawn website and mobile app wireframes. The authors first apply an extensive preprocessing pipeline: removing near-duplicate images using a per-class label-count distance metric, extracting per-class element shapes with a DLIB model to compensate for underrepresented classes, and converting images to grayscale before applying adaptive Gaussian thresholding and connected-component noise removal to produce cleaner binary sketches. UI element detection itself uses Mask R-CNN with a Feature Pyramid Network and ResNet-101 backbone, pretrained on COCO and fine-tuned on the competition's hand-drawn dataset of about 3,000 images across 21 element classes. The baseline model reaches high precision but struggles with recall, missing many smaller elements. To address this, the authors introduce a Multi-Pass Inference technique: detected regions are masked out with the background color and the edited image is passed through the model again, forcing it to surface elements missed on the first pass, with the two passes merged by confidence score and bounding-box overlap. This technique lifts Mean Average Precision at IoU above 0.5 from 57.34 in the baseline run to 64.12 in the final refined run, placing the team third on the shared task leaderboard. The paper positions its contribution as a first step toward automatically converting hand-drawn UI sketches into working website code.
