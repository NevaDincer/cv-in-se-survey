# Semantic Web Accessibility Testing via Hierarchical Visual Analysis

- **Year:** 2021
- **Venue/Source:** ICSE 2021 (43rd IEEE/ACM International Conference on Software Engineering)
- **DOI:** 10.1109/ICSE43902.2021.00143

## Metadata

- **se_area:** Testing (web accessibility testing)
- **se_task:** Automated detection of semantic (not just syntactic) web accessibility failures: inferring the high-level semantic regions/roles of a page (e.g. navigation, main, footer/contentinfo, search) that sighted users perceive visually, then checking whether this is correctly expressed via ARIA landmark markup for screen readers
- **cv_technique:** Prewitt operator (edge/derivative-based visual-feature detection used to determine whether a DOM element's rendered box is actually visually perceptible, distinguishing content regions from invisible spacing elements); a supervised CNN (Inception architecture) trained on 500 labeled icon images to visually recognize search icons; geometric/visual box-model analysis (computed bounding boxes, area, distance-from-center) combined with NLP (POS-tag variance, stemming of nearby label text) to score and classify regions into landmark roles
- **platform:** Web
- **rationale:** Context-driven / first-of-kind (existing tools only do syntactic markup checks and cannot detect "the markup does not conform to how the page is semantically perceived from a visual perspective," which requires visual analysis to establish ground truth); Robustness (visual, box-model-based grouping is used specifically because DOM hierarchy alone is unreliable: non-visible nodes can contain visible children, and CSS rendering can decouple visual layout from DOM structure)
- **artifact_type:** Full-interface (entire rendered page screenshot + DOM/computed box models are jointly analyzed to build a flat-then-hierarchical set of semantic groupings across the whole page)
- **eval_method:** Two complementary studies. RQ1: 10 human MTurk "Masters" evaluators judge precision/recall/F1 of AxeRay's inferred groupings and roles on 10 popular websites (87% F1 grouping, 90% F1 role); RQ2: (a) fault-injection experiment removing existing ARIA markup and checking re-detection (77.5% detected, vs 1.4% for a random baseline) across 30 real-world sites, and (b) manual TP/FP/TN/FN categorization of AxeRay's direct output on the same 30 sites (85.4% accuracy), benchmarked against the commercial syntactic tool SortSite, which detected zero semantic issues
- **challenges:** Scope intentionally limited to 4 ARIA landmark roles (main, navigation, contentinfo, search) out of 80+ ARIA attributes; false positives from visually navigation-like-but-not-navigation regions (e.g., a weather-forecast list of links); false negatives when the semantic-grouping stage fails to recognize a region (e.g., missing footer roles); focuses only on vision disabilities, not other accessibility dimensions (e.g., hearing)

## Summary

AxeRay is, per the authors' claim, the first automated tool to test *semantic* web accessibility rather than merely syntactic markup rules (e.g., "every img needs an alt attribute"). Its core insight is that existing tools can check syntax but cannot determine whether a page's ARIA markup actually matches what a sighted user visually perceives as the page's structure, a judgment that inherently requires visual analysis. AxeRay's pipeline has four stages: (1) Visual Objects Identification extracts textual, image and interaction objects from the DOM and filters them via a Prewitt-operator-based visual-perceptibility check (distinguishing genuinely visible content from invisible layout-only spacing elements); (2) Semantic Grouping builds seed groupings from the flat (non-hierarchical, since DOM nesting is visually unreliable) set of element box models, then filters/merges them via visual containment and equivalence rules into candidate semantic regions; (3) Semantic Role Inference scores each region against handcrafted geometric+linguistic formulas for main (area × POS-tag-variance), navigation (clickables-ratio / homogeneity), contentinfo/footer (clickables-ratio × distance-from-center / area), and search (a CNN icon detector plus nearest-neighbor text-field and keyword-stemming checks); (4) Markup Conformance checks whether any DOM element spatially and semantically covering an inferred region actually carries the matching ARIA role attribute, flagging a failure if not. Evaluated on 30 real-world sites, AxeRay substantially outperforms SortSite (the best existing syntactic tool), which detected zero semantic-level issues.
