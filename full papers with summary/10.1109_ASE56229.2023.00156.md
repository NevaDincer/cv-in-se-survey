# ATOM: Automated Black-Box Testing of Multi-Label Image Classification Systems

> **SCOPE WARNING**: this paper is borderline for a CV-in-SE survey. It isn't primarily about using computer-vision techniques to support a software-engineering task (GUI testing, UI code generation, and so on). Instead, the system under test, MICS, a multi-label image classifier, is itself a computer-vision/DNN system, and the paper's contribution is a black-box testing methodology (combinatorial label-combination coverage plus image-search-engine-based test-input retrieval plus metamorphic testing) for that CV system. The "CV technique" involved is largely the DNN classifiers being tested, not a CV technique used to accomplish an SE task. Worth deciding whether this survey's scope includes testing of CV/DNN systems as an SE task, or whether it should be excluded as CV-as-subject-under-test rather than CV-as-enabler-of-SE.

## Metadata

- **se_area:** Testing
- **se_task:** Black-box test-input generation and test-oracle identification for DNN-based multi-label image classification systems (MICS); test coverage criterion design
- **cv_technique:** Multi-label image classification DNNs as the systems under test (MSRN, MLGCN, DSDL, ASL, MCAR, MLD); image search engine retrieval + NLP (caption lemmatization, POS tagging via spaCy, WordNet synonym expansion) for realistic test-image collection; metamorphic image-processing operations (scale, brightness, contrast, rotation, Gaussian blur, sharpness, saturation) used as metamorphic relations
- **platform:** General (evaluated on academic datasets VOC and COCO, plus one industrial real-world Android/mobile photo-tagging application, PHOTO, from OPPO)
- **rationale:** Context-driven (label combinations chosen to reflect real-world object co-occurrence via image search volume); robustness (metamorphic testing to avoid needing ground-truth labels for oracle identification)
- **artifact_type:** Natural input (realistic web-sourced photographs used as test inputs, filtered for relevance rather than synthetically generated or adversarially perturbed)
- **eval_method:** Experiments across VOC (20 labels) and COCO (80 labels) with five state-of-the-art DNN models each, plus one industrial 32-label MICS; manual annotation (three independent student annotators, Cohen's Kappa 0.953) to validate test-image relevance; comparison against a random ImageNet-sampling baseline; metrics include number/proportion of label-error and unspecific-error images, proportion of confident vs. vulnerable label combinations, and a custom classification score; developer confirmation (92%) of industrial error-revealing images.
- **challenges:** Search-engine accuracy limits (irrelevant images collected, e.g., ambiguous super-category labels misleading search); scalability of exhaustive k-label-combination enumeration for k > 2 (combinatorial explosion, though rare combinations shrink the effective space); confidentiality constraints preventing disclosure of the industrial MICS's label space, model, and mAP; distinguishing label-combination-related errors from unrelated misclassifications in the test oracle.

## Summary

ATOM is a black-box testing framework for DNN-based multi-label image classification systems (MICS) that needs no access to model internals or training data. Its core idea is the k-label combination, a combinatorial-testing-inspired coverage criterion that treats every possible combination of k labels as a test target representing a correlation the MICS should correctly capture. For each target combination, ATOM builds search keywords, incorporating label super-categories and WordNet-derived synonyms, queries an image search engine, then filters out irrelevant results using NLP-based caption analysis (lemmatization, consecutive-label detection, part-of-speech tagging) to keep only images that plausibly contain all k target objects. Since no ground-truth labels exist for these web-sourced images, ATOM identifies test oracles by combining seven metamorphic relations, common transformations like brightness, contrast, and rotation, with label-subset reasoning: an image only gets flagged as a genuine label error if the k labels are absent under some outputs but the union of source and follow-up outputs still suggests the objects were present, isolating errors specifically tied to the label combination rather than unrelated confounds. Evaluated on VOC, COCO (ten DNN models total), and an industrial OPPO photo-tagging product, ATOM collected over 17,000 test images (99.6%/95.3% relevant for k=1/k=2), revealed thousands of label-combination errors in current MICSs (all with 81%+ validation mAP), found that 24 to 70% of common 2-label combinations it tests are missing from standard dataset validation sets, and had 92% of its flagged industrial errors confirmed by developers.
