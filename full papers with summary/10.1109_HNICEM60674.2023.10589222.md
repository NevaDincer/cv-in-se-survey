# Visual Test Framework: Enhancing Software Test Automation with Visual Artificial Intelligence and Behavioral Driven Development

- **Year:** 2023
- **Venue/Source:** 2023 IEEE 15th International Conference on Humanoid, Nanotechnology, Information Technology, Communication and Control, Environment, and Management (HNICEM)
- **DOI:** 10.1109/HNICEM60674.2023.10589222

## Metadata

- **se_area:** Testing
- **se_task:** GUI test automation (test creation, execution, maintenance) via visual regression testing
- **cv_technique:** Convolutional Neural Networks (CNNs) for image recognition; pixel-level image comparison / visual regression analysis (via Applitools Eyes SDK)
- **platform:** Web and mobile (GUI-based applications generally; case study built in Visual Studio 2019 targeting web pages)
- **rationale:** Ease of use (eliminates need for HTML-element identification/technical scripting expertise); robustness (detects visual defects/regressions that script-based automation misses); context-driven (screenshot vs. baseline comparison reflects actual rendered UI)
- **artifact_type:** Full-interface (screenshot-to-baseline-image comparison of entire GUI screens)
- **eval_method:** Mixed-methods descriptive evaluative design; survey/evaluation with 15 purposively-sampled professional software testers and test automation engineers (2+ years experience); statistical comparison (paired significance testing, p-values) of script-based vs. Visual AI automation across creation, execution, and maintenance phases
- **challenges:** Execution phase shows no significant improvement from Visual AI (runtime performance not meaningfully affected); framework depends on a commercial third-party service (Applitools) accessed via API key; small sample size (n=15) limits generalizability; limited prior research integrating Visual AI with BDD specifically, so tool/process maturity is still emerging

## Summary

This paper presents the Visual Test Framework, which pairs Visual AI (through the commercial Applitools Eyes SDK) with Behavior Driven Development, using Gherkin and SpecFlow, to cut the technical barriers and maintenance burden of traditional script-based GUI test automation. The framework has five modules: a Test Case repository, an Automation Tool (folder structure and dependencies such as NUnit, SpecFlow, and Selenium), a Visual AI module (screenshot-versus-baseline comparison using CNN-based recognition), a CI server, and a reporting module. Instead of locating and interacting with HTML elements, the Visual AI module takes screenshots and compares them against baseline images, returning pass or fail results, with a human in the loop approving expected UI changes or filing a defect for unexpected ones. Using a descriptive evaluative research design, the authors surveyed 15 professional testers and automation engineers in the Philippines and statistically compared script-based automation against Visual AI automation across three phases. The results show highly significant improvements for Visual AI in test creation and maintenance, but no significant difference in the execution phase, suggesting Visual AI's real benefit is cutting manual effort in script writing and UI-change maintenance rather than speeding up test runs. The paper also finds that Gherkin-based BDD scenarios significantly ease test creation, supporting the combined use of Visual AI and BDD for accessible, low-maintenance test automation.
