# PredART: Towards Automatic Oracle Prediction of Object Placements in Augmented Reality Testing

- **Year:** 2022
- **Venue/Source:** 37th IEEE/ACM International Conference on Automated Software Engineering (ASE '22)
- **DOI:** 10.1145/3551349.3561160

## Metadata

- **se_area:** Testing
- **se_task:** Automated test oracle generation for AR software (predicting whether a virtual object's placement in an Augmented Reality scene will be perceived as realistic/correct or as a noticeable placement error, to raise pass/fail warnings during automated regression testing)
- **cv_technique:** Hybrid deep image regression model combining a Convolutional Neural Network (CNN, 5 conv layers, 3x3 kernels) for image features with a Multi-Layer Perceptron (MLP, 3 layers) for numeric meta-features, fused via a concatenation layer and dense layers; baseline comparison against ResNet-18 (deep residual image regression)
- **platform:** General (AR platform-agnostic; evaluated via Unity MARS virtual test scenes targeting ARCore/ARKit-class mobile/wearable AR devices)
- **rationale:** 
- **artifact_type:** Full-interface (analyzes entire AR camera screenshots to judge overall scene realism, not a cropped/localized region, temporal video, or non-visual input; though it uses screenshot + numeric camera metadata jointly)
- **eval_method:** Custom-built dataset of 1,200 Unity MARS screenshots (720 training screenshots from a single controlled living-room scene with 3 object sizes (apple, lamp, chair) systematically varied by placement gap, distance, and horizontal/vertical viewing angle; 480 test screenshots from 5 more complex scenes: dining room, living room, office, factory/warehouse, backyard). Ground-truth labels obtained via Amazon Mechanical Turk (5 qualified workers per screenshot, binary realistic/floating-cutoff vote averaged into a 0.0–1.0 rating), with outlier analysis on labelers. Metrics: MAE, MSE, RMSE, accuracy (exact discretized-category match), and accuracy(±) (within one category). Baseline: ResNet-18 with naively concatenated features. Additional evaluations: per-scene and per-object breakdowns (RQ3), cross-object prediction where one object type is held out of training (RQ4), and external validation on 45 real screenshots (15 each, with synthetically mutated misplacements) from three official Unity AR Foundation sample apps (SimpleAR, Interaction, FeatheredPlanes) (RQ5). No formal user study beyond the MTurk labeling process itself.
- **challenges:** Authors explicitly report two limitations: (1) PredART is designed for use within virtual testing scenes (Unity MARS); porting it to physical phones/real-world AR scenes is uncertain because some features (vertical viewing angle, ground-truth misplacement) that are trivial to obtain in a simulator may be hard or impossible to measure at runtime on a real device with only sensor data. (2) The approach only handles static screenshots, so it cannot assess realism of moving/dynamic virtual objects; doing so would require video clips and additional temporal features (position/angle change over time), left as future work. The paper also self-reports a threat to validity: the evaluation dataset covers only a small number of scenes and three object types due to the cost of multi-worker MTurk labeling, and cross-object/larger-object (chair) prediction accuracy notably degrades, indicating limited generalization to object sizes/shapes not seen in training.

## Summary

PredART addresses test oracle generation for Augmented Reality software, specifically the problem that virtual object placement errors (objects appearing to float, sink, or be cut off relative to real-world surfaces) can only be judged by human perception, making automated AR testing difficult. The authors' pipeline has three stages: automatically driving a virtual AR camera through Unity MARS test scenes to capture screenshots of objects placed at systematically varied placement gaps, distances, and viewing angles; crowdsourcing realism labels for these screenshots via Amazon Mechanical Turk (five workers per image, averaged into a continuous 0–1 "reality score"); and training a hybrid deep regression model that processes the screenshot through a CNN branch and the camera/placement metadata through an MLP branch, concatenating and fusing both before a final dense regression head. The central contribution is this CNN+MLP fusion architecture, motivated by the observation that naively concatenating low-dimensional numeric features with high-dimensional raw image features causes the image features to dominate and produce a biased model. This is a problem the paper demonstrates concretely by showing PredART substantially outperforms a ResNet-18 baseline (85.0% vs 28.1% accuracy) that uses simple concatenation. A distinctive detail is the validation step applying the pretrained model, without retraining, to real screenshots from three official Unity AR Foundation demo apps with synthetically mutated object placements, showing the model transfers reasonably to previously unseen apps and objects, closely matching its cross-object generalization results.
