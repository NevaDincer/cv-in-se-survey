# Read It, Don't Watch It: Captioning Bug Recordings Automatically

- **Year:** 2023
- **Venue/Source:** 2023 IEEE/ACM 45th International Conference on Software Engineering (ICSE)
- **DOI:** 10.1109/ICSE48619.2023.00197

## Metadata

- **se_area:** Maintenance (bug reporting / bug reproduction support)
- **se_task:** Automated captioning (subtitle generation) of mobile app bug screen recordings to help developers understand and replay user actions, decomposed into three sub-tasks: action segmentation, action attribute inference, and natural-language description generation.
- **cv_technique:** Image-processing-based perceptual frame-similarity comparison (YUV luminance Y-Diff combined with SSIM, the Structural Similarity Index) for action-clip segmentation; Optical Character Recognition (PP-OCRv2) for keyboard detection and for extracting typed input text via frame-to-frame text-difference; a 3D-convolutional deep-learning model (X3D, built on ResNet-50 conv layers with residual connections) that jointly models spatial and temporal features across a clip to infer TAP touch-location coordinates; K-folds template matching (image-processing) to infer SCROLL direction/offset via motion trajectory; Faster-RCNN with ResNet-101 backbone and Feature Pyramid Networks (trained on the Rico dataset) for detecting 11 classes of GUI elements to support description generation; a transformer-based image-captioning model (reused from prior work, "Unblind Your Apps") to generate semantic captions for icons.
- **platform:** Mobile (Android); authors argue the purely image-based, non-intrusive design should generalize to other platforms (iOS, Web) with reasonable adaptation, though this is not empirically evaluated in this paper.
- **rationale:** Robustness (purely image-based and non-intrusive, requiring no app instrumentation, source-code access, or specific recording tool, and designed to be touch-indicator-independent after a preliminary study found 3 different indicator styles, default, cursor, and custom, in the wild); ease of use (converts a video developers would otherwise have to watch/replay into skimmable text-based subtitles); context-driven (uses global GUI context, absolute grid position and nearest-neighbor element relationships, to disambiguate elements whose text/icon is not uniquely identifiable, e.g., "tap the checkbox next to 'Dark Mode'").
- **artifact_type:** Temporal (segmenting a continuous screen recording into a sequence of discrete action clips over time) combined with localized (inferring a precise touch location / scroll offset / input text and identifying the specific GUI element acted upon within each clip).
- **eval_method:** Automated evaluation using 439 Android apps auto-explored via Droidbot to produce 10-minute recordings with ground-truth action metadata (across 3 touch-indicator styles); action segmentation evaluated via video-segmentation F1-score and accuracy against 5 image-processing baselines (ABS, HIST, SIFT, SURF, EDGE); action-attribute inference evaluated against two state-of-the-art baselines (V2S, GIFdroid); a separate usefulness user study with 8 participants (6 grad students, 2 professional developers) reproducing 10 real-world GitHub bug recordings, comparing CAPdroid-generated steps against original reporter-written steps on replay time and 5-point Likert clearness/conciseness/usefulness ratings, with Mann-Whitney U significance testing.
- **challenges:** Authors self-report: occasional over-segmentation of a single action into multiple clips due to slow resource/network loading or dynamic content (e.g., ads, embedded video) causing spurious frame-similarity drops; low color contrast between touch indicators and nearby icons causes false-positive action localization; OCR text-recognition errors (e.g., missing spaces) affect both keyboard detection and input-text inference accuracy; the underlying GUI-element object-detection model achieves only 51.45% mAP and the icon-captioning model only 60.7% accuracy on their respective test sets, capping the achievable quality of generated descriptions; the approach is currently scoped to English-language apps/keyboards, requiring additional effort to generalize to other languages; generality to other platforms (iOS, Web) is argued for but not empirically validated.

## Summary

This paper presents CAPdroid, the first approach to automatically generate natural-language "subtitles" for mobile app bug screen recordings, aiming to spare developers from having to repeatedly watch and pause raw videos to understand what a user did before a bug occurred. Motivated by a preliminary study of 1,000 real GitHub bug recordings, which found that 89% contain a touch indicator, split roughly into default (68%), emulator-desktop cursor (27%), and third-party custom (5%) styles, the authors design a purely image-based, non-intrusive, three-phase pipeline. First, Action Segmentation splits the recording into TAP/SCROLL/INPUT clips using a perceptual similarity score computed via YUV luminance difference and SSIM between consecutive frames, with distinctive similarity-curve signatures identifying each action type (and OCR-based keyboard detection disambiguating INPUT from TAP). Second, Action Attribute Inference recovers the fine-grained parameters of each action: TAP locations via a Conv3D/X3D deep model that jointly captures spatial and temporal cues (touch-indicator appearance, GUI transition animation) across 16 sampled frames; SCROLL offsets via K-folds template matching to track motion trajectories; and INPUT text via OCR-based text-difference extraction between keyboard-open and keyboard-close frames. Third, Description Generation uses an off-the-shelf Faster-RCNN GUI-element detector (trained on Rico) plus an icon-captioning model and computed positional/relational context to phrase each action into a template-based natural-language sentence (e.g., "Tap the checkbox next to 'Dark Mode'"), embedded as timed subtitles in the recording. Evaluated on 439 auto-explored apps, CAPdroid substantially outperformed five classical image-similarity baselines in action segmentation (0.84 video-F1, 0.93 accuracy, roughly 20% and 17% improvements over the best baseline, HIST) and two prior deep-learning-based tools (V2S, GIFdroid) in action-attribute inference (91.46% average accuracy, a 28% relative improvement over GIFdroid), notably because it is touch-indicator-independent (unlike V2S, which relies on indicator opacity fading and fails on non-default indicators) and can infer semantic INPUT text (unlike GIFdroid). A follow-up user study with 8 participants found that developers reproduced real GitHub bugs 59.8% faster using CAPdroid's generated steps compared to the original human-written reproduction steps, with statistically significant gains in clearness and conciseness, and participants specifically praised the absolute-positioning/element-relationship context and the value of the recording's embedded subtitles for revealing action timing.
