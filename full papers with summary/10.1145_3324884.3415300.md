# STIFA: Crowdsourced Mobile Testing Report Selection Based on Text and Image Fusion Analysis

- **Year:** 2020
- **Venue/Source:** ASE '20 (35th IEEE/ACM International Conference on Automated Software Engineering)
- **DOI:** 10.1145/3324884.3415300

## Metadata

- **se_area:** Testing (crowdsourced mobile testing) / Maintenance (bug report triage and deduplication)
- **se_task:** Crowdsourced test report selection and deduplication (clustering near-duplicate reports and selecting a representative report per cluster to reduce developer review effort)
- **cv_technique:** Canny edge detection (for candidate widget-image cropping from screenshots); Faster R-CNN (object detection, trained on 3,900 images across 13 Android widget categories, for widget recognition in screenshots); OCR (Baidu OCR, for extracting text from recognized widget images, used to link image and text features); SIFT (Scale-Invariant Feature Transform, for image feature descriptor extraction on widget images); PCA (dimensionality reduction to unify SIFT descriptor dimensions before clustering).
- **platform:** Mobile
- **rationale:** Context-driven (screenshots and bug-description text are analyzed jointly to establish an "image-text-fusion bug context," recognizing that prior work analyzed text and images independently and thus missed the link between reproduction-step object phrases and the actual problem widget shown in the screenshot); robustness (combining modalities improves duplicate-detection accuracy over single-modality baselines, evidenced by V-Measure gains when combining E1–E5 features vs. any subset).
- **artifact_type:** Localized (the CV pipeline crops and classifies individual widget images from screenshots, distinguishing a "problem widget" image from surrounding "context widget" images, rather than operating on the full screenshot)
- **eval_method:** Two research questions evaluated on a MOOCTEST-derived dataset of 150 crowdsourced reports (from 492 total) across 2 apps, manually labeled into 48 categories. RQ1 (feature extraction effectiveness) measured via per-feature recognition success rate A(Ei) across five feature types (reproduction steps, unexpected behavior, problem widget, problem widget image, context widget image), reporting 95.23% average text-feature recognition and 84.15% widget-image recognition. RQ2 (clustering/report-selection effectiveness) measured via V-Measure across four clustering algorithms (BIRCH, DBSCAN, GMM, K-Means) and different feature-input combinations, with BIRCH + all combined features achieving the best V-Measure (0.8764) and 87.64% overall duplicate-detection accuracy.
- **challenges:** Authors explicitly report accuracy limitations: E1 (reproduction steps) and E2 (unexpected behavior) recognition failures attributed to data/training limitations; E3 (problem widget) failures caused by reports lacking canonical/well-formed reproduction steps; E4 (problem widget image) and E5 (context widget image) failures attributed to insufficient widget training images and OCR precision problems. Additionally, if no widget image can be matched to the problem-widget text via the OCR+Word2Vec similarity threshold (0.9 cosine similarity), the entire report is abandoned/discarded rather than processed, a pipeline robustness limitation the authors acknowledge.

## Summary

STIFA addresses the problem of duplicate and low-value reports in crowdsourced mobile testing, where large numbers of workers submit reports mixing free-text bug descriptions with screenshots, and developers must manually deduplicate and triage them. The system has two modules. The Feature Extraction Module first classifies each sentence of a report's textual bug description (via a TextCNN classifier trained on 6,302 labeled crowdsourced reports) into "reproduction step" or "unexpected system behavior," then applies lexical analysis to the final reproduction step to extract an "object phrase" representing the likely problem widget mentioned in text. In parallel, it processes the report's screenshot: Canny edge detection crops candidate widget sub-images, and a Faster R-CNN model (trained on a custom 3,900-image, 13-category Android widget dataset) classifies each crop as a specific widget type, discarding unrecognized crops. An Image-Text Link Recognition step then applies OCR to each recognized widget image and computes Word2Vec cosine similarity between the OCR text and the textually-extracted problem-widget phrase; images exceeding a 0.9 similarity threshold are labeled the "problem widget image," others become "context widget images," and reports with no matching problem-widget image are abandoned. The Cluster Analysis Module vectorizes text features (Word2Vec) and image features (SIFT descriptors, PCA-reduced to uniform dimensionality), concatenates them, and clusters reports using BIRCH (selected as most effective after comparison against DBSCAN, GMM, and K-Means via V-Measure), selecting the centroid report of each cluster as the representative for developer review. Evaluated on 150 labeled reports from two apps, STIFA achieved 95.23% average text-feature extraction accuracy, 84.15% widget-image recognition accuracy, an 87.64% duplicate-report detection accuracy, and the best V-Measure among tested clustering configurations when using the full combined feature set, notably showing that text-only or image-only inputs yielded much smaller clustering gains than the fused representation.
