# Near-Duplicate Detection in Web App Model Inference

- **Year:** 2020
- **Venue/Source:** 2020 IEEE/ACM 42nd International Conference on Software Engineering (ICSE)
- **DOI:** 10.1145/3377811.3380416

## Metadata

- **se_area:** testing (automated web application crawling and model-based test generation)
- **se_task:** near-duplicate state detection used as a state abstraction function in web app model inference, deciding whether two crawled DOM states should be merged into a single state in the inferred model
- **cv_technique:** a comparative evaluation of five computer-vision-based near-duplicate detection algorithms applied to full-page screenshots, alongside five DOM/IR-based ones from web testing and information retrieval, namely perceptual image hashing (PHash) and block-mean hashing, whole-image comparison via color histogram and PDiff, structural similarity (SSIM), and SIFT keypoint feature matching
- **platform:** web (nine open-source web applications spanning PHP and JavaScript frameworks: Claroline, Addressbook, Dimeshift, Pagekit, Phoenix, PPMA, MRBS, MantisBT, PetClinic)
- **rationale:** context-driven (existing DOM-based state abstraction functions can be misled by cosmetic DOM differences that do not reflect real UI change, or can fail to merge visually identical pages whose DOM differs for incidental reasons; visual comparison offers an independent signal for judging whether two crawled states represent the same functionality)
- **artifact_type:** full-interface (whole rendered webpage screenshots compared pairwise between crawled states)
- **eval_method:** manual classification of 1,000 within-app state-pairs sampled from 493,000 pairs collected by crawling 6,000 Alexa top-ranked websites for a week, sorted into clone, near-duplicate, and distinct categories, with near-duplicates further split into cosmetic, dynamic-data, and duplication subtypes; statistical and Bayesian-optimization threshold derivation for each of ten algorithms; F1 classification accuracy measured on a held-out labeled sample and on 97,500 manually labeled state-pairs from nine open-source web apps; downstream impact on inferred crawl-model quality measured against manually created ground-truth models for 5-minute and 30-minute crawl budgets
- **challenges:** no single algorithm or threshold strategy, whether universal or app-specific, could correctly classify all functional near-duplicates without sacrificing state coverage; universal thresholds fit to a large random web dataset transferred poorly to specific target applications, and model quality improved substantially only once thresholds were tuned per app; the visual techniques were markedly slower than DOM-based ones in practice (PDiff explored around four states per minute against RTED's twenty-five), so despite competitive or superior raw classification accuracy they lost out on inferred model quality within a fixed crawl time budget; duplication-type near-duplicates, where added or removed elements do not change functionality, could not be reliably distinguished from genuinely distinct states by any technique, and inferred models were observed to degrade over longer crawls as these accumulated

## Summary

This paper presents the first systematic study of near-duplicate detection techniques used as state abstraction functions in web application model inference. The authors sample 493,000 within-app state-pairs from crawls of over 6,000 real-world websites and manually classify 1,000 of them into clone, near-duplicate, and distinct categories, further splitting near-duplicates into cosmetic, dynamic-data, and duplication subtypes. Ten detection algorithms drawn from three domains, information retrieval, web testing, and computer vision, are compared under both statistically derived and Bayesian-optimized thresholds. The computer vision techniques evaluated are perceptual and block-mean image hashing, whole-image comparison by color histogram and PDiff, structural similarity, and SIFT keypoint matching, all applied to full-page screenshots. Across F1 classification scores on a labeled sample and on 97,500 manually labeled pairs from nine open-source web apps, PDiff performs best in raw classification accuracy, but when the techniques are used to guide an actual crawler, RTED, a DOM tree edit distance method, produces the highest-quality inferred models because the visual techniques are considerably slower and explore fewer states within a fixed crawl budget. The study finds that no technique, universal threshold, or app-specific threshold can correctly classify every near-duplicate without losing coverage, that duplication-type near-duplicates cannot be reliably separated from genuinely distinct states, and that inferred models degrade over longer crawls as such near-duplicates accumulate.
