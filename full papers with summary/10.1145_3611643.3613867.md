# AG3: Automated Game GUI Text Glitch Detection Based on Computer Vision

- **Year:** 2023
- **Venue/Source:** ESEC/FSE '23, Proceedings of the 31st ACM Joint European Software Engineering Conference and Symposium on the Foundations of Software Engineering
- **DOI:** 10.1145/3611643.3613867

## Metadata

- **se_area:** Testing (GUI/game testing; localization and internationalization QA)
- **se_task:** Automated multilingual GUI text glitch detection in games (text overlap, text overstep) combined with automated game GUI traversal/exploration for test generation
- **cv_technique:** VGG16 (image encoding for scene-node similarity via cosine similarity in the traversal graph); YOLOX (multi-category GUI element detection: Button/Cancel/Pop-ups, and candidate abnormal text region localization); multilingual OCR engine (44 languages, text detection/recognition); Vision Transformer (ViT) (patch-level binary classifier used for the subtler text-overlap detection task)
- **platform:** Mobile games (Unity3D-based; evaluated on a first-person shooter and an action-RPG)
- **rationale:** Context-driven (game engines render screens in ways not exposable via ADB, so only screenshots are usable across arbitrary studios' engines); robustness (handles device/screen-resolution/language fragmentation causing text spillover or overlap); ease of use (non-intrusive: no source code, SDK, or app instrumentation required; minimal configuration before testing a new game)
- **artifact_type:** Full-interface (whole-screenshot scene traversal and classification) combined with localized detection (bounding-box-level abnormal text regions)
- **eval_method:** Empirical evaluation with precision/recall/accuracy/error-rate on a real, imbalanced dataset of historical glitch screenshots (1,658 normal vs. 55 text-overlap / 288 text-overstep glitches), compared against the GLIB baseline; a novel "Text-Coverage" metric comparing Intelligent Traversal vs. Random Traversal across two games in three languages; two-year industrial deployment study across 27 games (2,790 confirmed bugs; QA report generation time reduced from 12 person-days to ~1 day)
- **challenges:** Real glitch examples are rare relative to normal screenshots, requiring a custom digital-image-processing-based synthetic data generation algorithm; game screens are not accessible through standard Android GUI-tree tools, forcing a purely image-based pipeline; the detection algorithm deliberately favors recall over precision (initial version ~30% precision) because false positives are easy to filter manually but missed bugs are costly, at the expense of noisier reports.

## Summary

AG3 is an industrial computer-vision-based tool developed at ByteDance to automatically detect multilingual text glitches (text overlap and text overstep) in mobile game GUIs. Because game engines render screens in ways that make GUI elements undetectable via standard Android instrumentation tools (e.g., ADB), the authors adopt a purely image-based approach requiring no source code or SDK access. The system has two main components: an "Intelligent Traversal" module that builds a directed scene-traversal graph using VGG16-derived screenshot embeddings for state/node similarity, combined with GUI element detection, multilingual OCR, and scene classification to prioritize exploration of text-rich screens; and a "Vision-Only Text Glitch Detection" module that uses YOLOX for candidate abnormal text region localization plus a Vision Transformer-based binary classifier (for the subtler text-overlap case) and a standalone YOLOX detector (for the more visually obvious text-overstep case). A notable contribution is a digital-image-processing-based synthetic data generation algorithm that programmatically creates realistic overlapping/overstepping text on real screenshots to address the rarity of naturally occurring glitch examples in training data. The paper also introduces a new "Text-Coverage" metric to evaluate traversal effectiveness independently of source-code-based coverage metrics, since game apps cannot be measured with conventional code/activity coverage. After two years of internal deployment across 27 games, AG3 uncovered over 2,790 confirmed bugs and reduced manual multilingual QA reporting time from 12 person-days to about 1 day per report, illustrating a deliberate industrial design choice to prioritize recall over precision because false positives are cheap to filter manually while missed bugs are costly to end users.
