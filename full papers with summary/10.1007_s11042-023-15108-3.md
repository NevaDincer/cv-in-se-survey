# Web pages from mockup design based on convolutional neural network and class activation mapping

- **Year:** 2023
- **Venue/Source:** Multimedia Tools and Applications
- **DOI:** 10.1007/s11042-023-15108-3

## Metadata

- **se_area:** Development
- **se_task:** Classification and weakly-supervised semantic segmentation of common web UI elements (text boxes, text areas, buttons, checkboxes, date-time pickers, dropdowns, radio buttons, value sliders, tables, charts) in screenshots and mockups, as a first step toward an automated/real-time dynamic web-page-building or co-creation prototyping tool
- **cv_technique:** Custom CNN classifiers (baseline 'KerasCNN' vs. authors' 'WebMockerCNN', both conv+maxpool+FC architectures); Class Activation Mapping (CAM), a weakly-supervised semantic segmentation technique that replaces the FC layer with Global Average Pooling (GAP) so a classification-only CNN can produce a localization heatmap using only image-level labels, with no bounding-box/in-image annotation required
- **platform:** Web
- **rationale:** Ease of use (CAM's core appeal is that it needs no bounding-box annotation, significantly simplifying the dataset creation process versus traditional segmentation models like Mask R-CNN/YOLO); Context-driven (aimed at supporting agile UX prototyping/MVP workflows where quickly turning an idea into a testable application matters)
- **artifact_type:** Component (2200 cropped single-element images, 10 classes x 220 each, for classification/CAM training) and Full-interface (20 hand-built simple web page mockups used only to visualize/evaluate the CAM segmentation heatmap output)
- **eval_method:** Two-phase validation. (1) Classification: a quick uncross-validated comparison of KerasCNN vs. WebMockerCNN (McNemar's test, p=0.00, confirming a real performance difference), followed by full 5-fold then extended grid-search hyperparameter tuning (62 hyperparameter-pair candidates x 5 folds = 310 fits over optimizer/learning-rate, activation/kernel-initializer, and dropout/FCL-neuron-count triples), landing on Adam(lr=0.01)+ReLU+GlorotNormal+dropout0.5+1024 FCL neurons as best, reaching 95.71% (±0.73%) 10-fold CV accuracy and 97.03% on a non-cross-validated 100-epoch run; McNemar's test again confirms this beats the runner-up (tanh-activation variant). (2) Segmentation: the winning CNN was converted into a CAM network (FC replaced by GAP) and qualitatively inspected via heatmaps on 20 held-out web-page mockup images (Figs. 13-17); no quantitative segmentation metric (IoU, precision/recall against ground-truth masks) was computed, by the authors' own explicit choice.
- **challenges:** The paper's central, self-reported negative finding: classification accuracy (95.71-98.40%) is explicitly not indicative of segmentation quality, and the resulting CAM heatmaps are qualitatively judged insufficient for real use, e.g. text-box/dropdown/button classification heatmaps often key off text presence or straight lines rather than element shape, radio-buttons/checkboxes get confused with disconnected text labels, and range-slider heatmaps only highlight one side of the element; several classes are visually too similar (radio vs. checkbox, textbox vs. textarea, tabular vs. general page grid); the dataset has no class for generic containers/panels/groups; no ground-truth boxes exist to compute a reliable segmentation metric, and the authors explicitly declined to build one because the 20-image validation set is small and the results were already visibly poor enough not to need automated confirmation

## Summary

This paper sets out to test, and largely complicates, the idea that a lightweight, annotation-free CNN technique called Class Activation Mapping could power real-time web-page-building tools straight from UI mockup screenshots. The authors build and release a purpose-made 2,200-image, 10-class dataset of common web widgets, sourced through targeted image searches mixing element names with style keywords like "bootstrap" or "hand-drawn" to keep the visual styles varied, and deliberately keep the dataset small since the goal is testing the CAM concept rather than chasing scale. The work runs in two stages. First, two CNNs, an off-the-shelf "KerasCNN" baseline and the authors' own "WebMockerCNN," get compared, and WebMockerCNN wins after a serious hyperparameter search across optimizer, learning rate, activation, initializer, and dropout settings, landing on 95.71% ten-fold cross-validated accuracy. Second, and this is the actual contribution, the winning classifier's fully connected layers get swapped for global average pooling, turning it into a CAM network that lets the same image-level labels double as weak segmentation training data with no extra annotation cost. The resulting heatmaps, inspected on 20 constructed mockups, tell an honest, somewhat deflating story: classification accuracy is strong, but the segmentation heatmaps often key off text content or a single straight line rather than a widget's actual shape, and visually similar classes like radio buttons and checkboxes get confused. The authors conclude plainly that CAM isn't suited for cases needing precise segmentation, and frame the paper as a cautionary, exploratory contribution rather than a working prototyping tool.
