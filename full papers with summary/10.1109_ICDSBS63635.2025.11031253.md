# Automated Webpage Generation from Hand-Drawn Mockups Using ResNet-50 and Deep Learning

- **Year:** 2025
- **Venue/Source:** 2025 International Conference on Data Science and Business Systems (ICDSBS)
- **DOI:** 10.1109/ICDSBS63635.2025.11031253

## Metadata

- **se_area:** Design / Development (specifically the design-to-code / UI-implementation handoff step, translating UI mockups into front-end implementation)
- **se_task:** Automatic HTML code generation from hand-drawn (paper-sketched, camera-captured) web-page mockups, i.e., mockup-to-code / sketch-to-code generation
- **cv_technique:** Classical image preprocessing via OpenCV (RGB-to-grayscale conversion, Gaussian blur for noise reduction, thresholding, contour detection for rectangle/shape discovery, morphological operations, erosion and dilation, for shape cleanup) to localize and crop candidate UI-element regions; a custom CNN (trained ~200 epochs, binary cross-entropy loss, RMSProp optimizer) for object recognition/classification of cropped elements (text box, dropdown, button, checkbox, plus header/footer/image types mentioned elsewhere in the paper) into 4+ component classes; a ResNet-50-based model (via transfer learning, flattening ResNet-50's output, adding dense layers with ReLU and a final softmax layer, optimized with SGD) for prediction/classification of HTML elements from the grayscale mockup image.
- **platform:** Web (webpage/HTML generation is the stated goal, though the pipeline is presented as generalizable to broader UI/software-engineering design-to-code tasks)
- **rationale:** Ease of use (removing the need for designers/developers to hand-code UI from mockups, letting designers iterate on designs without writing code); reduction of repetitive/tedious manual coding effort and design-development iteration overhead
- **artifact_type:** Full-interface (the entire hand-drawn mockup image of a page is processed) combined with localized element extraction (individual UI components, buttons, text fields, headers, footers, are detected via contour analysis, cropped, and classified independently before being reassembled into the full HTML page)
- **eval_method:** Training/validation on a dataset built by combining images from Microsoft's Sketch2Code tool, the Pix2code dataset, and other sources, manually decomposed into individual UI-element images; reported metrics are training/object-recognition accuracy of 93% and overall validation accuracy of 80% (the paper's conclusion separately cites "96% object recognition accuracy" and "73%" generalization accuracy, indicating some internal inconsistency in reported numbers); no baseline/comparative quantitative evaluation against Pix2code, REDRAW, REMAUI, or Sketch2Code is performed, these are discussed only qualitatively in Related Work.
- **challenges:** (1) The system currently handles a limited set of UI element types (text boxes, dropdowns, buttons, checkboxes, headers, footers, images) and the authors note further refinement is needed for generalization to "wider ranges of inputs and more complex designs"; (2) no support yet for interactive/dynamic designs, cross-page transitions, or animations (explicitly cited as a limitation of related tools like Pix2code and REMAUI, which this system aims to but has not yet fully addressed); (3) reliance on grayscale conversion for analysis discards color information that could be relevant to design fidelity; (4) reported accuracy figures are inconsistent across the paper's sections (93%/80% in the abstract vs. 96%/73% in the conclusion), suggesting limited evaluation rigor; (5) hand-drawn sketch quality/variability (camera-captured, hand-sketched input) is a general source of noise the OpenCV preprocessing pipeline must compensate for.

## Summary

This paper presents a deep-learning pipeline that automatically converts hand-drawn, camera-photographed website mockups into functional HTML code, aiming to close the traditionally manual, iterative gap between UI/UX design and front-end development. The pipeline first preprocesses the captured mockup image with OpenCV (grayscale conversion, Gaussian blur, thresholding, contour detection) to identify and crop rectangular regions corresponding to candidate UI elements, then applies morphological operations, erosion and dilation, to clean up the detected shapes. A CNN classifies each cropped region into UI-component categories such as text box, dropdown, button, or checkbox, while a ResNet-50-based transfer-learning model performs a second-stage prediction of HTML elements directly from the grayscale mockup, drawing on ResNet-50's depth for structural image features. Detected and classified components then map to appropriate HTML tags and get assembled, with help from the Bootstrap framework and the contour-derived coordinates, into complete HTML code, exposed through a web application with admin login, image upload, and code-generation pages. The authors report 93% object-recognition accuracy and 80% overall validation accuracy on a dataset assembled from Microsoft's Sketch2Code tool, Pix2code, and other sources. The paper positions its contribution against existing sketch and design-to-code tools (Pix2code, ReDraw, REMAUI, Sketch2Code), arguing those struggle with interactive or dynamic designs and complex multi-page layouts, and sketches future extensions including natural-language-to-HTML generation and voice-driven code customization for accessibility. Worth flagging: the paper's own accuracy figures differ between its abstract (93%/80%) and conclusion (96%/73%), which matters when weighing evaluation rigor across the survey.
