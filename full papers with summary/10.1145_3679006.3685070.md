# Metamorphic Testing of Image Processing Applications: A General Framework and Optimization Strategies

- **Year:** 2024
- **Venue/Source:** Proceedings of the 9th ACM International Workshop on Metamorphic Testing (MET '24), Vienna, Austria
- **DOI:** 10.1145/3679006.3685070

## Metadata

- **se_area:** Testing
- **se_task:** Metamorphic testing (fault detection / conformance testing) of image-processing applications; test-input (follow-up image) generation
- **cv_technique:** CycleGAN (for realistic follow-up test-image generation / style transfer); OpenCV-based image transformations (rotation, transposition, scaling, erosion/dilation, blur, sharpening, affine transform) used to derive follow-up images per metamorphic relation. Note: the systems under test themselves also embody CV/ML techniques (binary dilation, KNN, CNN/AlexNet, YOLOv3), but these are test subjects, not the SE-task-performing technique.
- **platform:** General (not mobile/web/desktop-specific; applies to generic image-processing services/algorithms)
- **rationale:** Robustness (fault detection effectiveness of image processing applications); realism/ecological validity of test images (motivation for using CycleGAN instead of only simple OpenCV transforms)
- **artifact_type:** Natural input (CycleGAN-generated follow-up images intended to closely resemble realistic scenarios, e.g., sunny→snowy style transfer)
- **eval_method:** Mutation testing (MutPy-generated executable mutants across 4 subject programs: Dilation, KNN, AlexNet, YOLO); mutation score (MS) as fault-detection-effectiveness metric; time-to-first-fault (TF) as performance metric; comparison of MS/TF with and without the EquivalentMR and SSampling optimization strategies; 100 repeated runs averaged to control for randomness
- **challenges:** (1) Computational cost of MT becomes very high when using a large set of test images and all applicable MRs together; (2) complex image transformations (e.g., style transfer) are not well supported by simple OpenCV-based follow-up generation, motivating the CycleGAN component; (3) generating follow-up images that are realistic/close to real-world scenarios is difficult; (4) fault-detection effectiveness varies substantially by application category. MRs were far less effective for the YOLOv3 object-detection subject (mutation scores 20.83%–38.53%) than for image classifiers (KNN, AlexNet: 50%–78.65%), a limitation the authors report but do not fully resolve.

## Scope note

Borderline fit for the CV-in-SE survey. This paper's primary subject matter is *testing of* image-processing/ML applications (a binary dilation algorithm, a KNN classifier, an AlexNet CNN classifier, and a YOLOv3 detector), meaning these systems are the *software under test*, not a computer-vision technique being applied to accomplish a software-engineering task. The one point of genuine overlap with the survey's scope is that the framework uses **CycleGAN** (a CV/generative technique) to synthesize realistic follow-up test images for metamorphic testing, which could be read as "CV technique used to support an SE task (test-case generation)." Recommend a close look before inclusion; if included, frame it narrowly around the CycleGAN-based follow-up-image-generation component rather than the whole paper.

## Summary

This paper proposes a general metamorphic testing (MT) framework for image processing applications, addressing three gaps in prior MT work: the lack of a framework generalizing across application categories, high computational cost, and difficulty generating realistic follow-up test images. The framework identifies and composes 21 metamorphic relations (MRs) drawn from and extending prior literature, and uses CycleGAN to generate follow-up images that mimic realistic scenarios (e.g., style transfer such as sunny-to-snowy) in addition to standard OpenCV transformations (rotation, blur, scaling, erosion/dilation, etc.). Two optimization strategies are introduced to reduce cost: EquivalentMR, which groups MRs into ten equivalence classes based on similarity of their transformation and randomly samples one MR per class, and SSampling, which randomly subsamples the source test-image pool. A supporting tool, MT4I, implements the framework. Evaluation across four subjects (a binary dilation algorithm, KNN, AlexNet, and YOLOv3) using mutation analysis shows strong fault-detection effectiveness for Dilation/KNN/AlexNet but notably weaker results for YOLOv3 object detection (25% mutation score). EquivalentMR reduced the number of MRs used by more than 50% with only 1.85%–4.22% degradation in fault-detection effectiveness, and SSampling achieved similar cost/effectiveness trade-offs, reaching ~96% effect-of-optimization at a 50% sampling rate. A notable detail is that composite MRs (combinations of elementary transformations, e.g., rotate-then-blur) generally outperformed their elementary components in fault-detection effectiveness.
