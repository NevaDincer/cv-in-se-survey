# A Replication Package for "It Takes Two to TANGO: Combining Visual and Textual Information for Detecting Duplicate Video-Based Bug Reports

- **Year:** 2021
- **Venue/Source:** ICSE '21 Companion (43rd International Conference on Software Engineering: Companion Proceedings)
- **DOI:** 10.1109/ICSE-Companion52605.2021.00067

## Metadata

- **se_area:** Maintenance (bug/issue triage), specifically duplicate bug report management, adjacent to Testing (video-based bug reporting)
- **se_task:** Duplicate video-based bug report detection / retrieval (ranking candidate duplicate videos from an issue tracker given a query video)
- **cv_technique:** SimCLR (contrastive self-supervised visual representation learning) for frame/video embeddings; SIFT (Scale-Invariant Feature Transform, via a trained visual codebook/bag-of-visual-words) for keypoint-based frame matching; OCR (Tesseract, via pytesseract) for extracting on-screen text from video frames, combined with information-retrieval (text-retrieval) techniques. Similarity between frame sequences computed via longest common subsequence (LCS) and a weighted-LCS variant.
- **platform:** Mobile (Android)
- **rationale:** Robustness (visual similarity captures GUI-state duplication that text alone misses, since different users may describe the same bug differently) combined with context-driven use of text (OCR-extracted on-screen text) to disambiguate visually similar but semantically distinct screens; ease-of-use for end users/crowd-testers who only need to record a screen video rather than write detailed textual descriptions.
- **artifact_type:** Temporal (the core artifact is a video/frame-sequence; similarity is computed over ordered sequences of frames using LCS-style sequence alignment) with a Full-interface component (each frame is treated as a whole-screen embedding/keypoint set rather than a localized widget-level detection)
- **eval_method:** Empirical evaluation on 180 video-based bug reports collected from six open-source Android apps via a user study, organized into 4,860 duplicate-detection tasks (per the paper's "setting #2"); performance measured via ranking metrics (e.g., proportion of duplicates found in top-2 candidates: 83%) and developer-effort/time savings (≈65% reduction). The replication package additionally supports re-running the full pipeline (data + trained SimCLR/SIFT/OCR+IR models + intermediate outputs + evaluation scripts) and includes a standalone command-line tool for applying the visual (SimCLR) model to new data.
- **challenges:** The command-line tool released with the artifact only supports the visual (SimCLR) sub-model, not the combined visual+textual TANGO approach, because the combination step "needs to be tuned depending on vocabulary overlap in an app," meaning the textual/OCR fusion is not directly generalizable across apps without app-specific tuning. This implies a broader challenge for CV+text fusion approaches in SE: combination weighting is dataset/app-dependent rather than universally transferable.

## Summary

This is an ICSE 2021 Companion artifact/replication-package paper describing the reproducibility materials for TANGO, a technique for detecting duplicate video-based bug reports in mobile apps. TANGO's core contribution (described in the original ICSE'21 paper, replicated here) is combining visual and textual information extracted purely from screen-recording videos to rank candidate duplicate reports without relying on structured textual bug descriptions. The visual side uses two alternative feature extractors, SimCLR (a contrastive self-supervised deep learning model producing frame embeddings) and SIFT (classical local keypoint descriptors aggregated into a visual codebook), and compares frame sequences using longest common subsequence (LCS) and a weighted-LCS variant to capture temporal alignment of GUI state transitions across two videos. The textual side applies OCR (via Tesseract/pytesseract) to extract on-screen text from each frame, feeding an information-retrieval-based similarity model (OCR+IR). A combination module fuses visual and textual similarity scores into a final ranked candidate list. The described artifact packages TANGO's full Python/Java source code (organized into prep, features, eval, model, approach, and combinations modules, distributed via PyPI and Docker), the underlying dataset of 180 video-based bug reports from six open-source Android apps (collected via a user study), trained model checkpoints (SimCLR weights, SIFT codebooks), all intermediate outputs (extracted frames, OCR text, rankings), and the evaluation harness reproducing the original paper's results: 83% top-2 duplicate-retrieval accuracy and roughly 65% reported reduction in developer time spent finding duplicates. Notably, the artifact also ships a standalone CLI tool for running just the SimCLR visual model on new query/corpus video pairs, though the fully combined visual+textual pipeline is not exposed this way since its fusion weighting is app-specific.
