# Adaptive attention fusion network for cross-device GUI element re-identification in crowdsourced testing

- **Year:** 2024
- **Venue/Source:** Neurocomputing, vol. 580, article 127502 (Elsevier)
- **DOI:** 10.1016/j.neucom.2024.127502

## Metadata

- **se_area:** Testing (maintenance-adjacent: reproduction/regression testing within crowdsourced software testing, CST)
- **se_task:** Automated GUI element re-identification to support "reproduction testing," matching a GUI element captured in a bug-report screenshot on one device/OS/resolution to the corresponding element on a different device, so crowd workers (or an automated pipeline) can replay test steps without scripting skills or stable UI identifiers (IDs, XPath, accessibilityIdentifier).
- **cv_technique:** Custom CNN architecture (ERINet) with shared-weight twin backbones (interchangeable VGG-11 / ResNet-18 / DenseNet-121, fully-convolutional, no FC layers); UNet-inspired attention sub-network trained on alpha-channel element masks to separate element from background; a learnable scalar factor (α) that adaptively blends attention features with backbone features before a 4-layer convolutional classifier + global average pooling + softmax; baseline comparisons against classical CV descriptors SIFT, SURF, ORB.
- **platform:** Mobile (Android apps; explicitly framed as cross-device/cross-OS, mentions iOS/Android/web GUI heterogeneity as motivation)
- **rationale:** Robustness (background/resolution/device variation, partial occlusion, blur from poor screen-recording quality) is the dominant driver; also context-driven design (attention mechanism explicitly built to ignore irrelevant background pixels and focus only on the semantically relevant element region)
- **artifact_type:** Localized. The model operates on a cropped GUI element image superimposed on a background patch (128x128 element canvas + 148x148 background patch), not a full-screen interface.
- **eval_method:** Binary same/different classification accuracy on a curated dataset (31,098 training element images + 115,704 test element images extracted from 66 real Android apps, 67 background images); four-category test protocol (identical-element/different-bg, identical-element/identical-bg-with-occlusion, distinct-elements/same-bg, distinct-elements/different-bg); ablation study isolating the contribution of attention features and the learnable factor across three backbones; head-to-head comparison of correct-rate against SIFT/SURF/ORB; qualitative feature-map visualizations; runtime/GPU-memory profiling (RTX 3080, ~9.16 ms/inference at test time).
- **challenges:** (1) GUI elements have far less texture than natural photographs, limiting transferability of classic image-matching methods; (2) element backgrounds vary arbitrarily across devices/resolutions/software versions, causing background leakage into learned features; (3) some elements are non-image-based (pure vector/flat UI), so background cannot simply be cropped away a priori; (4) elements may be partially obscured or extend past screen edges; (5) crowdsourced screen recordings are frequently blurry/low-quality, requiring explicit robustness testing across blur intensities 0.9-0.3; (6) risk of overfitting motivated deliberately small backbone choices (VGG-11/ResNet-18/DenseNet-121 rather than larger variants).

## Summary

This paper targets a concrete pain point in crowdsourced software testing: reproducing a previously reported bug requires crowd workers to replay test steps on a different device than the one used during exploratory testing, and neither hard-coded element identifiers nor naive image matching survive cross-device GUI layout changes. The authors propose ERINet, a Siamese-style CNN with a dedicated attention branch trained using ground-truth alpha-channel masks (element versus background) borrowed from a UNet-style segmentation setup, but repurposed to gate the backbone's feature maps rather than segment anything. A distinctive piece of the architecture is a single learnable scalar, called the Learnable Factor, added to the attention map before it multiplies the backbone features, which lets the network calibrate how much to trust the attention signal instead of hard-wiring that weight. Ablations show this factor and the attention mechanism together drive the largest error-rate reductions, roughly 17 to 23% relative, depending on backbone and test category, with the biggest gains in the hardest case: identical elements against very different backgrounds. The model clearly beats SIFT, SURF, and ORB (97.7% versus 68 to 79% correct rate) while staying light enough for near-real-time inference at about 9 milliseconds per pair. The dataset itself, 31,000 training and 115,000 real-app test element images with synthetic background compositing and simulated blur, is a reusable artifact worth noting for future CV-in-SE GUI-matching work.
