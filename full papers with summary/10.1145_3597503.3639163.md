# Semantic GUI Scene Learning and Video Alignment for Detecting Duplicate Video-based Bug Reports

- **Year:** 2024
- **Venue/Source:** ICSE 2024 (46th International Conference on Software Engineering)
- **DOI:** 10.1145/3597503.3639163

## Metadata

- **se_area:** maintenance
- **se_task:** duplicate video-based bug report detection (bug triage support)
- **cv_technique:** Vision Transformer (ViT) with DINO self-supervised distillation training for visual GUI scene/frame representation; Bag of Visual Words + TF-IDF video encoding via K-Means codebook; EAST scene text detector for text region localization; TrOCR (Transformer-based OCR) for text recognition; modified longest common substring (LCS) alignment weighting video frames by cosine similarity
- **platform:** mobile
- **rationale:** context-driven, robustness
- **artifact_type:** full-interface, temporal
- **eval_method:** quantitative benchmark evaluation (mRR/mAP) on thousands of duplicate detection tasks (7,290 per the abstract; 7,920 per the methodology section) built from 270 video-based bug reports (90 real + 180 synthetic/original bugs) across nine Android apps; statistical significance testing via Wilcoxon paired test; ablation studies over visual/textual/sequential components and their combinations; comparison against prior baseline detector Tango; qualitative analysis using saliency maps (AGF) and ViT self-attention visualization plus EAST vs. Tesseract OCR bounding-box comparison
- **challenges:** distinguishing near-duplicate video frames and GUI screens with subtle visual differences; handling dynamic/variable app content (e.g., web browser apps navigating different websites) that causes high visual dissimilarity between true duplicates; videos of variable length and differing reproduction step sequences/speeds; small or low-contrast on-screen text that scene text detectors may miss; computational overhead of frame sampling and codebook construction; limited generalization evidence beyond Android/English-language apps (dataset does not cover other languages or platforms like iOS)

## Summary

This paper introduces Janus, an automated technique for detecting duplicate video-based bug reports in Android app issue trackers, addressing the maintenance-phase bug triage problem of avoiding redundant investigation of reports depicting identical GUI bugs. Janus formulates duplicate detection as an information retrieval task and combines three complementary computer vision and NLP-based components: a visual component that encodes GUI screen layouts using a Vision Transformer trained with the DINO self-supervised distillation scheme, discretized into a Bag-of-Visual-Words TF-IDF representation; a textual component that localizes and recognizes on-screen text using the EAST scene text detector and TrOCR, encoded as TF-IDF text vectors; and a sequential component that aligns video frames using a modified longest-common-substring algorithm weighting later frames more heavily, since bug manifestations typically occur near the end of the recording. The authors built an extended benchmark of thousands of duplicate detection tasks from 270 videos covering both synthetic and real Android bugs across nine apps, and compared Janus against the prior state-of-the-art detector Tango. The best Janus configuration, combining all three modalities, achieved mRR/mAP of 89.8%/84.7%, outperforming Tango by roughly 9% with statistical significance, translating to fewer videos developers must inspect to find a duplicate. Qualitative analysis using saliency maps and attention visualization showed ViT better captures GUI layout and component boundaries than CNN-based baselines, while EAST more reliably detects small or low-contrast text than Tesseract OCR. Limitations include reduced effectiveness on apps with highly dynamic content and untested generalization to non-Android platforms or other languages.
