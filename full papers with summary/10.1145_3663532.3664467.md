## Summary

This paper investigates whether integrating novelty search into NEATEST, an existing neuroevolution-based test generator for Scratch games, can help overcome "challenging fitness landscapes" that hinder automated test-input generation for games. NEATEST represents each test case as a neural-network agent evolved (via the NEAT algorithm) to reliably reach a specific target source-code statement, guided by a fitness function combining approach level and branch distance computed over the game's control dependence graph. The authors identify two recurring failure modes of this objective-function-only approach: (1) *deceptive* landscapes, where achieving the goal temporarily requires moving away from it (e.g., a player must detour around a wall, increasing Euclidean distance to a target portal before it can decrease), which the objective function penalizes; and (2) landscapes *lacking guidance*, where the relevant condition compares non-numerical values (e.g., string-based menu-state identifiers), giving the search no meaningful gradient. Drawing on prior novelty-search literature from evolutionary robotics, the authors extend NEATEST by adding a novelty score, computed via k-nearest-neighbors cosine-similarity distance over a hand-crafted, genre-agnostic behavioral feature vector (sprite position, heading, costume, size, private variables, target distance, plus global variables and mouse position), as a secondary, tie-breaking fitness criterion during parent selection. In a case study on two Scratch games representing different genres (CreateYourWorld, a maze-navigation game, and PokéClicker, a menu-driven clicker game), the Fitness+Novelty configuration achieved statistically significant coverage improvements over the baseline (82.73% vs. 79.52%, p<0.01, effect size 0.85, for CreateYourWorld; 47.99% vs. 45.79% for PokéClicker), and notably reached the maze's next level in all 10 repetitions versus only 7/10 for the baseline. The authors attribute the improvement to novelty search helping the algorithm escape coverage plateaus once the behavior archive fills with many similarly-rated individuals, which increases selection pressure toward previously unexplored states. The paper is explicitly framed as an initial/exploratory investigation, with future work aimed at more sophisticated multi-objective (Pareto-based) integrations of novelty and at using novelty to improve fault-detection by generating behaviorally diverse test cases for the same target state.
