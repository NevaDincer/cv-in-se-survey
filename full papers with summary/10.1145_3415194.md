# From Lost to Found: Discover Missing UI Design Semantics through Recovering Missing Tags

- **Year:** 2020
- **Venue/Source:** Proceedings of the ACM on Human-Computer Interaction, Vol. 4, No. CSCW2, Article 123
- **DOI:** 10.1145/3415194

## Metadata

- **se_area:** development (UI/GUI design artifact management and retrieval tooling for a collaborative design-sharing platform)
- **se_task:** automated recommendation of missing semantic tags for GUI design images uploaded to a design-sharing site, so that designs can be more reliably found through text-based tag search
- **cv_technique:** a hybrid deep learning model combining a ResNet CNN, pretrained on ImageNet and fine-tuned on the GUI design dataset, for visual feature extraction from the design screenshot, with a two-layer CNN over GloVe word embeddings of the design's existing tags for textual feature extraction; the two embeddings are concatenated and fed into per-tag binary classifiers; a Softmax-based saliency map visualization is used to highlight the image regions driving each predicted tag
- **platform:** web (static UI design images and mockups uploaded to the Dribbble design-sharing platform, not live application screenshots)
- **rationale:** automation (replacing or augmenting manual, inconsistent community tagging with a model that proactively recommends missing tags before or after upload); ease of use (designers are not required to reason about a controlled tagging vocabulary themselves)
- **artifact_type:** full-interface (complete static UI design images and mockups, as distinct from live captured application screens)
- **eval_method:** empirical study of tagging behavior across 61,700 UI designs mined from 226,000 crawled Dribbble graphical designs, with open coding of the 1,000 most frequent co-occurring tags into a five-category, roughly forty-subcategory taxonomy cross-checked against Material Design and the Mobile Design Pattern Gallery; one binary classifier trained per tag for the 26 tags with more than 300 examples, evaluated across four train/validation/test splits, reaching average accuracy of 0.7875 to 0.8272 for the combined image-plus-tag model versus 0.6009 to 0.6249 for color-histogram baselines and 0.7306 to 0.7522 for a tags-only ablation; a pilot user study with 10 participants comparing UI design retrieval using the model's predicted tags against Dribbble's default search across 5 queries and control versus experimental groups of 10, 30, and 50 candidates, with differences in related-candidate count, satisfaction, and diversity scores tested with the Mann-Whitney U test at p < 0.01 or p < 0.05
- **challenges:** predictions fail on visually ambiguous designs that lack a distinctive feature the classifier can key on, such as a design tagged "music" with no visible player element; the assumption that tags within the same category are mutually exclusive does not always hold, since some designer disagreement reflects genuine differences in preference rather than tagging error, which introduces label noise the model cannot resolve; the evaluation covers only the 26 tags with at least 300 example designs, leaving generalization to rarer or newly emerging tags untested; only a single train/validation/test split was used rather than k-fold cross-validation, which the authors note may introduce bias; the current system operates reactively, adding tags after upload, rather than as a proactive check integrated into the platform's upload flow, since the authors lack direct access to the underlying site

## Scope note

This paper's task is tag recommendation for a UI design sharing platform rather than a software testing, development, or maintenance activity in the usual sense. It is included because it addresses GUI design artifact search and retrieval, a task closely related to other UI/GUI design mining and knowledge-discovery papers already in this corpus (such as Gallery D.C.), and because the CNN-based visual-plus-textual tag prediction model is the paper's central technical contribution rather than an auxiliary step.

## Summary

This paper studies tag quality on Dribbble, a UI design sharing platform, and proposes a deep learning method to recommend missing tags for GUI design images. An empirical analysis of 61,700 UI designs finds that community-contributed tags are inconsistent in vocabulary and frequently incomplete, a finding confirmed through interviews with four professional designers. The authors build a taxonomy of UI-related tags spanning platform, color, app functionality, screen functionality, and screen layout categories, then train one binary classifier per frequent tag using a hybrid model that combines a ResNet CNN fine-tuned on the design image with a small CNN over GloVe embeddings of the design's existing tags. Because tags within the same category tend to be mutually exclusive, negative training examples are drawn from designs carrying other tags in the same category as the target tag. The combined image-plus-tag model reaches an average accuracy of 0.8272, outperforming color-histogram baselines and single-modality ablations, and a saliency-map visualization is used to show which image regions and existing tag words drove each prediction. A pilot user study with ten participants finds that retrieval using the model's predicted tags surfaces substantially more related UI designs than Dribbble's default search, with higher self-reported satisfaction and diversity scores, differences confirmed by Mann-Whitney U tests. The authors note that predictions still fail on visually ambiguous designs and that some apparent errors reflect genuine differences in designer preference rather than model mistakes.
