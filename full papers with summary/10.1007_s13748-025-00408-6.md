# Artificial intelligence for context-aware visual change detection in software test automation

- **Year:** 2025
- **Venue/Source:** Progress in Artificial Intelligence (Springer)
- **DOI:** 10.1007/s13748-025-00408-6

## Metadata

- **se_area:** Testing (visual/UI regression testing within software test automation)
- **se_task:** Visual change/regression detection between screenshots of an application (across software versions, window sizes, and platforms)
- **cv_technique:** YOLOv5 (object detection for UI control detection); graph construction from spatial nearest-neighbors; recursive graph-matching similarity algorithm combining OCR-based textual similarity (cosine similarity of text embeddings) and perceptual (average) hashing for visual similarity
- **platform:** Web (desktop browser) and mobile; general web application UIs, evaluated cross-platform (desktop-to-mobile)
- **rationale:** Context-driven (explicit goal: capture contextual/spatial relationships between UI elements that pixel-wise/region-based methods miss) and robustness (explicitly evaluated for robustness to window resizing, cropped/partially visible UIs, and desktop-vs-mobile layout differences)
- **artifact_type:** Full-interface (whole-screenshot comparison producing a change heatmap over the entire UI, built from all detected controls in the screen)
- **eval_method:** Three custom-built datasets from real screenshots: (1) 250 desktop website screenshots with 8 synthetic change types (add/move/recolor/duplicate/remove/resize/swap control) yielding 1,750 image pairs; (2) same but with a cropped/shifted region simulating window resizing, another 1,750 pairs; (3) 180 manually annotated desktop–mobile screenshot pairs of the same application. Metrics: precision, recall, F-score at three IoU thresholds (0.75, 0.5, 0.25). Baselines: pixel-wise comparison (PWC) and a region-based change detector (RCD) built on the same YOLO detections. Hyperparameters (K neighbors, hash-difference threshold H, text-similarity threshold TS, neighbor-similarity threshold NS) tuned via 70/30 split per dataset. Also reports YOLOv5 control-detector performance (precision/recall/mAP) per UI-control class on a separate 14,155-train/2,000-test annotated control-detection dataset. Data/code released on GitHub.

## Summary

This paper proposes a graph-based, context-aware method for detecting visual UI changes between software screenshots, aimed at automated visual regression testing. The pipeline has four stages: a YOLOv5 object detector locates and classifies UI controls (24 classes) in both the original and modified screenshots; each screenshot's controls become nodes of an unweighted graph, with edges connecting each node to its K spatially nearest neighbors; a recursive graph-matching algorithm then computes node correspondence by recursively comparing neighborhoods, falling back on OCR-derived textual cosine similarity and perceptual-hash visual difference when nodes have already been visited; and unmatched nodes are flagged as changes and rendered as heatmaps over the images. The main contribution is this novel graph-construction-plus-recursive-similarity formulation for change detection, which is layout-aware rather than coordinate-dependent, letting it handle window resizing, cropped views, and cross-platform (desktop-vs-mobile) layout differences that defeat pixel-wise and simple region-based comparison. A distinctive detail is the hybrid node-similarity formula (Eq. 3), which sums OCR-text cosine similarity with the inverse of a normalized average-hash difference, letting textual and purely visual cues compensate for one another during recursive neighbor matching. Evaluated on three custom datasets (synthetic desktop edits, cropped/resized desktop screenshots, and manually annotated desktop-mobile pairs) against pixel-wise and region-based baselines using precision/recall/F-score at three IoU thresholds, the method matched or substantially outperformed both baselines in the two harder, layout-shifted scenarios, though it trailed pixel-wise comparison in the trivial, perfectly aligned case.
