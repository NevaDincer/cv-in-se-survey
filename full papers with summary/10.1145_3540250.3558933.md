# SemCluster: A Semi-supervised Clustering Tool for Crowdsourced Test Reports with Deep Image Understanding

- **Year:** 2022
- **Venue/Source:** ACM ESEC/FSE '22 (Joint European Software Engineering Conference and Symposium on the Foundations of Software Engineering), Singapore
- **DOI:** 10.1145/3540250.3558933

## Metadata

- **se_area:** Testing (crowdsourced mobile application testing)
- **se_task:** Duplicate/near-duplicate crowdsourced bug (test) report detection and clustering
- **cv_technique:** Traditional CV widget/region detection on screenshots combined with a CNN (VGG-16-based) classifier trained on 36,000+ widget images (14 classes) to extract 4096-dimensional content-feature vectors; screenshots organized into a 4-level tree structure (screenshot → group → line → column) for structural comparison; APTED (All Path Tree Edit Distance) algorithm for structural-feature distance
- **platform:** Mobile
- **rationale:** Context-driven (exploits the semantic connection between screenshot content and textual bug descriptions, which prior approaches ignored); robustness (semi-supervised binding-rule guidance is shown to substantially outperform both text-only and image-only unsupervised baselines)
- **artifact_type:** Full-interface (whole-screenshot structural and content analysis), combined with natural-language bug report text
- **eval_method:** Empirical comparison against the SETU baseline (Wang et al.) and two ablation configurations (image-only, text-only) plus an unsupervised variant (Unspvsd), on a manually labeled dataset of 847 crowdsourced test reports across 18 mobile apps (109 total bug categories); measured via Precision, Recall, F-measure, Purity, Adjusted Rand Index (ARI), and Normalized Mutual Information (NMI)
- **challenges:** Prior deduplication methods relied on shallow image analysis and ignored the semantic link between screenshots and textual descriptions, degrading clustering accuracy; GUI structure cannot always be derived automatically from APK files (some widget areas may be blank/inaccessible), motivating the hybrid CV+DL widget-extraction pipeline; parameter thresholds for binding rules (e.g., IoU threshold λ=0.75, distance thresholds α/θ/β/ω) were tuned empirically rather than derived analytically.

## Summary

SemCluster addresses the well-known problem that crowdsourced mobile app testing produces large volumes of duplicate bug reports (reportedly ~82% duplication in industrial data). Unlike prior unsupervised, text-only or shallow-image-analysis approaches, SemCluster extracts four complementary features per report: a Structural Feature (a four-level widget tree built by combining classical CV widget localization with a CNN/VGG-16 classifier, compared via APTED tree-edit distance), a Content Feature (per-widget 4096-dim CNN embeddings matched via IoU and coordinate proximity, compared with Euclidean distance), and two textual features, Bug Behavior and Reproduction Step, extracted with a pretrained TextCNN, Word2Vec, and a DTW-based sequence-matching algorithm. These four distances are combined into a weighted semi-supervised distance, and the paper's main methodological contribution is a set of "semantic binding rules" (Must-Link / Cannot-Link constraints derived from distance thresholds) that guide a K-Medoids clustering process, correcting cases where a report would otherwise be misassigned. Evaluated on 847 real crowdsourced reports from 18 apps, SemCluster substantially outperforms the SETU baseline (e.g., +76.8% F-measure, +2372% ARI) and both image-only and text-only ablations, confirming that jointly modeling screenshot structure/content and textual bug behavior, bound together via explicit rules, yields markedly better deduplication than either modality alone or fully unsupervised clustering.
